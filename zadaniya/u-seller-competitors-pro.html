Ежедневный дайджест о конкурентах на почту

Скрипт, который раз в день проверяет блоги, открытые сообщества ВКонтакте и страницы сайтов конкурентов и присылает на почту 3-5 пунктов по каждому: что нового и что это значит для вас. Карточки, цены и отзывы на маркетплейсах он не разбирает

около 120 мин · уверенный · без VPN · задача «Следить за конкурентами»

Черновик на согласовании: текст может уточняться.

Чем делать

Python, YandexGPT API (Yandex AI Studio), VK API, Яндекс Почта

Что подготовить

  • Python 3.10 или новее и привычка запускать скрипты в терминале
  • Аккаунт Yandex AI Studio с привязанной картой российского банка, API-ключ и идентификатор каталога (folder_id)
  • Ящик на Яндекс Почте и пароль приложения для него. Пароль начинает действовать через 2-3 часа, поэтому создайте его первым
  • По желанию: сервисный ключ приложения VK ID, если следите за сообществами ВКонтакте
  • 3-10 конкурентов, у которых есть блог с RSS, открытое сообщество ВКонтакте или страница цен и новинок на сайте

Шаги

1. Получите ключи

Сделайте по уроку p5 разделы «Шаг 0» (пароль приложения для почты), «Шаг 1» (ключ YandexGPT) и, если нужен ВКонтакте, «Шаг 2». Ключи сохраните в файл secrets.sh по разделу «Шаг 4»: не вставляйте их в чат и не пишите в код.

2. Соберите код из урока

Поставьте зависимости по разделу «Шаг 3». Код в уроке p5, разделы «Шаг 5» - «Шаг 12»: соберите блоки по порядку в один файл main.py. Блок Telegram из раздела «Шаг 11» добавляйте, только если Telegram работает у вас и у тех, кто читает дайджест.

3. Впишите конкурентов

Замените примеры в SOURCES на своих конкурентов. Для блога укажите адрес ленты RSS, для сообщества ВКонтакте короткий адрес после vk.com/, для страницы без RSS адрес и CSS-селектор блока с ценами или новинками. Карточки на маркетплейсах сюда не добавляйте: для них есть разбор без кода.

4. Запустите вручную

Выполните две команды из раздела «Шаг 13»: . ./secrets.sh и python3 main.py. В первый раз по каждому источнику разбираются 3 последние записи, страницы только запоминаются. Запустите второй раз: скрипт должен ответить «Нового нет, письмо не отправляю».

5. Проверьте и поставьте на расписание

Прочитайте письмо и пройдитесь по списку. Если всё в порядке, настройте ежедневный запуск по разделу «Шаг 14»: cron на своём компьютере или сервере либо GitHub Actions, если GitHub у вас открывается.

  • Письмо пришло, и в нём есть все конкуренты, у которых было что-то новое
  • Каждый пункт опирается на реальный пост, статью или изменение на странице, а не на догадку модели
  • Ошибки источников, если были, перечислены в конце письма
  • Повторный запуск не присылает те же записи: файл state.json сохраняется между запусками
  • Ключи и пароли лежат только в secrets.sh или в секретах GitHub, не в коде и не в репозитории

Если получилось почти

  • Письмо не ушло, ошибка входа в SMTP: пароль приложения начинает действовать через 2-3 часа после создания. Ещё проверьте, что в настройках Почты в разделе «Почтовые программы» включён доступ и что в SMTP_PASSWORD стоит пароль приложения, а не обычный
  • Каждый день приходит одно и то же: state.json не сохраняется между запусками. В cron он лежит в папке проекта, в GitHub Actions его сохраняет последний шаг workflow из урока
  • Страница «меняется» каждый день: в выбранный блок попадают дата, счётчики или случайные товары. Сузьте selector до нужной части страницы
  • Модель отвечает ошибкой 400: адрес модели устарел. Сверьте имя модели с актуальным списком в документации Yandex AI Studio
