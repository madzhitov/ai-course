Помощник продавца Wildberries: карточки пачкой из папки с товарами

Утилита, которая из папки с фото и описаниями товаров пачкой делает черновики карточек Wildberries (заголовок, описание, характеристики по справочнику WB, ключевые слова), и проверенная загрузка первой карточки в кабинет

около 120 мин · уверенный · без VPN · задача «Собрать помощника продавца»

Черновик на согласовании: текст может уточняться.

Чем делать

Python, Yandex AI Studio (Qwen3.6 35B, YandexGPT Lite 5), WB API (Контент)

Что подготовить

  • Аккаунт Yandex Cloud с платёжным аккаунтом и доступ владельца к кабинету продавца Wildberries (токен API создаёт только владелец)
  • Python 3.10+ и умение запускать скрипты в терминале
  • Папка на каждый товар: 1-3 фото и файл brief.txt с фактами (категория, цвет, состав, размеры)
  • Размеры упаковки в сантиметрах и вес с упаковкой в килограммах

Шаги

1. Настройте Yandex AI Studio

Урок p20, раздел «Шаг 1»: в aistudio.yandex.ru нажмите «Создать API-ключ», и AI Studio сам создаст сервисный аккаунт с нужными ролями. Ключ показывают один раз, скопируйте сразу. Запишите folder_id каталога, в котором создан ключ.

2. Создайте токен Wildberries

В кабинете продавца откройте «Интеграции по API», нажмите «+ Создать токен», вкладка «Для интеграции вручную». Тип персональный: он для ваших собственных программ. Категория только «Контент», уровень доступа «Чтение и запись». Токен показывают один раз, и он действует 180 дней; нигде его не публикуйте и не отправляйте в чат.

3. Соберите проект

Раздел «Шаг 3» урока: папка, виртуальное окружение, зависимости, файл .env с тремя ключами и папки goods/item_001 с фото и brief.txt. Добавьте .env в .gitignore, если используете git. В brief.txt пишите состав и размеры: чего там нет, модель не должна додумывать.

4. Скопируйте код и запустите без загрузки

Файлы prompts/clothes.txt, generator.py, wb_uploader.py и main.py возьмите из разделов «Шаг 4» - «Шаг 7» урока p20. Найдите ID предмета: python main.py --find-subject джинсы. Затем выполните python main.py --goods-dir goods --category clothes --subject-id ВАШ_ID на двух-трёх товарах: рядом с фото появится card.json, в кабинет ничего не уходит. Для второй проверки отправьте card.json в чат этим запросом.

Проверь эту карточку для Wildberries на запрещённые обещания и выдуманные факты: «лечит», «сертифицирован», «гарантирует», «лучший», состав и размеры, которых нет в моём описании.
Моё описание: [содержимое brief.txt]
Карточка: [содержимое card.json]
Верни список проблемных мест и что поправить.
Если данных не хватает, сначала задай мне до трёх вопросов.

5. Проверьте характеристики

Код загрузки в уроке, раздел «Шаг 6»: он сам сопоставляет названия характеристик из card.json с id из справочника предмета и пишет в лог, каких обязательных не хватает. Допишите недостающие факты в card.json руками, ничего не угадывая.

6. Загрузите один товар и проверьте

Раздел «Запуск и проверка»: запустите main.py с --upload, --subject-id, ценой, размерами и габаритами упаковки на одном товаре. Ответ 200 ещё не значит, что карточка создана: создание идёт асинхронно, до 30 минут. Потом выполните python main.py --check-errors. Остальные товары загружайте после этого.

  • Состав и размеры в карточке совпадают с brief.txt, ничего не добавлено от себя
  • photo_facts в card.json совпадает с тем, что на фото
  • subject-id взят из --find-subject, габариты и вес упаковки ваши
  • --check-errors не показывает ошибок по артикулу, карточка видна в кабинете

Если получилось почти

  • Yandex отвечает ошибкой доступа: ключ скопирован не целиком, у сервисного аккаунта нет роли ai.languageModels.user на каталог или у ключа не та область действия. Проще всего создать ключ заново кнопкой «Создать API-ключ» в AI Studio
  • Yandex отвечает 400 на имя модели: эту версию вывели из эксплуатации, возьмите актуальное имя из списка моделей AI Studio и поправьте VISION_MODEL или TEXT_MODEL
  • Ответ модели не разбирается как JSON: добавьте в промпт «не пиши ничего, кроме JSON» и понизьте temperature до 0.1
  • Wildberries отвечает 401, 403 или 429: 401 значит токен истёк или скопирован не целиком, 403 значит токен не той категории (проверьте запросом GET https://content-api.wildberries.ru/ping), 429 значит слишком часто, в коде уже есть пауза 6 секунд и повтор. Если карточки не создаются, проверьте остаток лимита: GET /content/v2/cards/limits
