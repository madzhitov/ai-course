Claude vs GPT vs Gemini: когда что

Цель: понимать сильные стороны каждой топ-модели и выбирать под задачу Время: ~35 минут Источник: Anthropic, OpenAI, Google docs + practical use 2025–2026

Зачем тебе этот урок

В 2026 топ-три моделей — Claude (Anthropic), GPT (OpenAI), Gemini (Google). Все три почти на равных в общих бенчмарках, но в реальных задачах различия большие. Использовать «модель по привычке» — упускать 30–50% качества. Этот урок даёт практическую матрицу выбора.

3. Бенчмарки — почему им нельзя верить полностью

MMLU, HumanEval, GPQA, MATH — топ-3 модели набирают близкие баллы. Но:

  • Тест-сет загрязнён. Модели «видели» эти задачи в обучающих данных.
  • Узкий охват. Бенчмарки не покрывают «реальное использование» — длинный код, цепочка из 10 запросов, обработка JSON.
  • Стиль не меряется. Две модели с одинаковыми баллами могут давать совершенно разные ответы по полезности.

Что меряет лучше:

  • LMSys Arena (chatbot-arena.com) — рейтинг по слепому сравнению живыми пользователями. Лучший proxy реального качества.
  • SWE-Bench — реальные пул-реквесты на GitHub, кто чинит больше.
  • Aider Leaderboard — для кода в реальных репозиториях.

4. Длинный контекст — большая разница

Все три заявляют большой контекст. Качество на длинном контексте разное.

  • Needle in a haystack тест: прячут одно предложение в 200k токенов и спрашивают про него. Claude 4.5 — почти 100% recall до 1M токенов. GPT-5 — 95%+ до 400k. Gemini 2.5 — 90–98%, держит 1M, на 2M проседает.
  • Reasoning over long context: когда нужно не просто найти, а связать факты в разных местах документа — Claude и GPT-5 существенно лучше Gemini.
  • Долгие агентные задачи: Claude Sonnet 4.5 — единственная модель, которую Anthropic протестировала на 30+ часах автономной работы без распада плана. Это новый класс задачи: «работай весь день сам».

Практическое следствие: для серьёзной работы с длинными документами Claude — оптимум.

5. Цены и стратегия

В 2026 цены flagship-моделей сжались в 2–3 раза за год. Реальная экономика на 1M запросов в день (средний запрос 10k input + 1k output):

  • Claude Sonnet 4.5 ($3/$15): ~$45/день
  • GPT-5 ($1.25/$10): ~$22/день
  • Gemini 2.5 Pro ($1.25/$10): ~$22/день
  • Claude Haiku 4.5 / GPT-5 mini / Gemini 2.5 Flash: $1–4/день
  • Prompt caching снижает повторяющийся input ещё в 10×

Двухмодельная стратегия: 80–90% запросов на «дешёвую» модель (Haiku 4.5 / GPT-5 mini / Flash), 10–20% сложных — на flagship (Sonnet 4.5 / GPT-5 / Gemini 2.5 Pro). Простой роутер по эвристике (длина, ключевые слова, наличие кода) экономит 70–90% бюджета без потери качества там, где это видно пользователю.

6. Tools / Function Calling

  • OpenAI Responses API / GPTs — самая зрелая и стандартизированная экосистема (тысячи плагинов).
  • Claude tools + MCP — качество вызовов высокое, особенно на цепочках из 50+ шагов. MCP стал индустриальным стандартом для подключения внешних инструментов (поддерживают и OpenAI, и Google).
  • Gemini function calling — догнал технически, но экосистема меньше.

Уроки 13, 19, 22 в этом курсе работают на всех трёх.

7. Multimodal — реальные различия

  • Текст + картинки — все три на одном уровне для простых задач.
  • OCR со сложным layout — GPT-5 и Gemini 2.5 Pro лучше Claude.
  • Видео в контексте — только Gemini. До 2-часового видео в одном запросе.
  • Аудио (voice-in/voice-out) — GPT-5 Realtime API лучший. Gemini Live API — догоняет.
  • Генерация картинок — это другие модели: DALL·E 3 / GPT-Image (OpenAI), Imagen 4 (Google), сторонние Midjourney/FLUX. Anthropic картинки не генерирует.

8. Тонкости и подводные камни

  • Сравнивай на своих реальных задачах, не на «общем впечатлении». Сделай 10 типичных промптов и прогони через все три.
  • Цены меняются ежеквартально. Перепроверяй официальные страницы.
  • «Лучшая модель» не существует. Существуют «лучшая под задачу X у бюджета Y в момент Z».
  • Vendor lock-in. Не строй приложение на одной модели — оборачивай в свой слой абстракции (LiteLLM, LangChain), чтобы переключать.

9. Глоссарий

Needle-in-a-haystack

Тест на способность модели найти конкретный факт, спрятанный в очень длинном тексте.

LMSys Arena

Сайт, где пользователи слепо сравнивают пары моделей. Главный «честный» рейтинг.

Двухмодельная стратегия

Дешёвая модель для большинства запросов, дорогая — для сложных. Маршрутизация по эвристике или классификатору.

  1. Возьми 5 своих типичных запросов из работы.
  2. Прогони через Claude Sonnet 4.5, GPT-5, Gemini 2.5 Pro (можно через LMSys Arena в режиме direct chat — бесплатно).
  3. Сравни: качество, скорость, цена.

11. Проверь себя

1. Когда Claude лучше GPT?
Длинные документы (200k+), серьёзный код, юридика/медицина с дисклеймерами, цепочки из 10+ tool calls.

2. Когда GPT лучше Claude?
Творческие задачи без жёстких ограничений, multimodal с аудио/видео-входом, готовая экосистема плагинов (GPTs).

3. Когда Gemini — выбор?
Видео в контексте, дешёвая массовая обработка (Flash), очень длинный контекст (1M+).

4. Почему стандартным бенчмаркам не стоит доверять?
Загрязнены тест-сетами в обучении, узкий охват, не меряют стиль и реальное использование.

5. Что такое двухмодельная стратегия и зачем?
Дешёвая модель для большинства запросов, дорогая для сложных. Экономит 70–90% бюджета без потери качества там, где важно.

12. Что должно остаться в голове

  1. Claude — для длинного контекста, точности, осторожности.
  2. GPT — для творческих задач, multimodal с аудио, готовой экосистемы.
  3. Gemini — для видео в контексте, очень длинного окна и дешёвой массовой обработки.
  4. Бенчмарки врут — смотри LMSys Arena и тестируй на своих задачах.
  5. Не залипай на одной модели — оборачивай в абстракцию и сравнивай ежеквартально.
  6. Двухмодельная стратегия (cheap + expensive) экономит до 90%.
