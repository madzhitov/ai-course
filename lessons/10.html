Урок 10. Low-code приложения с ИИ

Цель: собрать рабочее AI-приложение без кода и понимать, где это правильный путь, а где нет Время: ~50 минут Источник: generative-ai-for-beginners/10

Зачем тебе этот урок

Не всякая AI-задача требует Python и сервера. Огромный пласт задач — «когда приходит письмо → суммаризируй → положи в Notion» — собирается за 20 минут в low-code инструменте. Без программирования. И работает годами.

Low-code AI — это особая суперсила, потому что:

  • Идею можно проверить за час, а не за неделю.
  • Не-разработчики (маркетологи, рекрутеры, юристы) автоматизируют свою работу сами.
  • 90% реальных AI-юзкейсов в компаниях — это интеграция готовых моделей в существующие данные/процессы, а не разработка моделей.

1. Что такое «low-code AI»

Это инструменты, где ты собираешь приложение из готовых блоков на холсте: триггер (что-то происходит) → шаги (что сделать) → действия (куда положить результат). Один из шагов — вызов LLM.

Базовый кирпич: триггер → LLM-шаг → действие.

Примеры:

  • Новое письмо в Gmail → GPT суммаризирует → пост в Slack.
  • Форма на сайте → GPT категоризирует запрос → создаёт тикет в Linear.
  • Telegram-сообщение → Claude переводит → отправляет в другой чат.
  • RSS-фид → суммаризация → ежедневный дайджест в Notion.

3. Полный пример в Make: AI-помощник для писем

Задача: когда приходит письмо в Gmail с темой «Запрос» — GPT категоризирует (продажи / поддержка / спам), пишет 2-строчное саммари и постит в нужный канал Slack.

Сценарий (5 шагов):

  1. Триггер: Gmail — «Watch emails» с фильтром по теме.
  2. OpenAI: Create Completion. Промпт: «Категоризируй письмо в одну из категорий: sales / support / spam / other. Верни JSON {category, summary}». В body передаёшь {{1.text}}.
  3. Router: ветвится по {{2.category}}.
  4. Slack: Send Message в канал #sales, #support и т.п.
  5. Google Sheets: Append row — лог всех писем для аналитики.

Время сборки с нуля — 20 минут. Стоимость работы — ~$0.0002 за письмо. Сценарий работает 24/7 без сервера.

4. Microsoft Copilot Studio коротко

Если ты в корпоративном Microsoft-мире (Teams, SharePoint, M365), Copilot Studio — твой инструмент. Это no-code конструктор чат-ботов:

  • Drag-and-drop диалоговые потоки.
  • Готовые коннекторы к 1000+ систем.
  • Можно подключить свои данные (SharePoint-документы → RAG-бот).
  • Деплой одной кнопкой в Teams.

В России доступ ограничен — но если работаешь в международной компании, это де-факто стандарт для корпоративных AI-помощников.

5. Где low-code заканчивается

Low-code прекрасен, пока ты в его границах. Где он ломается:

  • Сложная бизнес-логика. Когда «если А и Б, но не В, и при этом дата позже Г, и пользователь из категории Д» — визуальные блоки превращаются в кашу.
  • Большой объём. Make/Zapier берут деньги за каждую операцию. На 100k операций в день код в облаке дешевле в 10–100 раз.
  • Низкая задержка. Low-code платформы добавляют 200–800 мс на шаг. Если нужен реалтайм — не годится.
  • Сложные данные/состояние. Когда нужна нормальная БД, миграции, версионирование — нужен код.
  • Тонкая работа с LLM. Streaming, function calling с многошаговыми диалогами, кастомные эмбеддинги — обычно проще написать.

6. AI-агенты-конструкторы

Отдельный класс — конструкторы AI-агентов:

  • OpenAI GPTs — кастомные GPT-боты с инструментами, бесплатно при подписке ChatGPT Plus.
  • Claude Projects — для долгих задач с контекстом (Урок c2).
  • Botpress, Voiceflow — для голосовых/текстовых ботов.
  • Dify, FlowiseAI, n8n с LangChain-нодами — open-source конструкторы AI-агентов с RAG и tool-use.

Это middle ground: больше возможностей, чем чистый Make, но не нужен код.

7. Тонкости и подводные камни

  • Цена операций. Каждый шаг в Make/Zapier = операция. Сценарий из 5 шагов на 1000 событий в день = 150k операций/мес. Прицельно смотри биллинг.
  • Hardcoded API-ключи. Большинство low-code платформ хранят ключи в зашифрованном виде, но это всё равно вне твоего контроля. Для чувствительных данных — self-host (n8n).
  • Сложно тестировать. Нет git, нет CI. Случайно сломал сценарий — пользователи начали получать мусор.
  • Сложно мониторить. Логи есть, но искать ошибку в 100 запусках за сутки — больно. Заранее настраивай error-handler с уведомлением в Slack.
  • Vendor lock-in. Сложно перенести сценарий из Make в Zapier. Если платформа поднимет цены — переезд болезненный.

8. Глоссарий

Триггер

Событие, которое запускает сценарий. Новый email, новая строка в Sheets, расписание.

Действие (Action)

Шаг, который что-то делает: вызов API, отправка письма, создание записи в БД.

Webhook

HTTP-ручка, которая принимает данные извне и запускает сценарий. Универсальный триггер.

Router

Ветвление сценария по условию. Аналог if-else.

Iterator

Перебор массива. Аналог for-loop.

9. Практика (50 минут)

  1. Зарегистрируйся в Make (бесплатный тариф).
  2. Собери сценарий: RSS какого-нибудь блога (или Telegram-канал через Telegram Bot) → OpenAI («суммаризируй в 3 предложения») → результат в Notion/Sheets/себе на email.
  3. Проверь, что работает на 3 разных постах.
  4. Добавь обработку ошибок: если OpenAI вернул ошибку — отправь в отдельный канал.
  5. Запиши в progress.md, сколько времени заняло, и сколько операций ушло.

10. Проверь себя

1. Когда low-code лучше, чем код?
Простая интеграция между сервисами, прототип за час, владелец не-разработчик, объём небольшой (<1000 операций/день).

2. Когда low-code хуже, чем код?
Сложная логика, большой объём, низкая задержка, нужен git/CI/тесты, нужны кастомные данные.

3. Что такое «операция» в Make/Zapier и почему за неё берут деньги?
Каждый отдельный шаг сценария = операция. Сценарий из 5 шагов на 1 событие = 5 операций. Платишь за фактическое потребление.

4. Чем GPTs от OpenAI отличаются от Make-сценария?
GPT — это чат-бот с памятью и инструментами, а Make — автоматизация фоновых процессов. GPT отвечает пользователю, Make работает по триггерам.

5. Что такое webhook и зачем он нужен в low-code?
HTTP-эндпоинт. Внешняя система отправляет на него POST с данными → запускается сценарий. Универсальный триггер для систем, у которых нет прямого коннектора.

11. Что должно остаться в голове

  1. Low-code AI = триггер + LLM-шаг + действие. Собирается за 20 минут.
  2. Make — лучший старт; n8n — если нужна приватность; Zapier — если уже в нём; Copilot Studio — для MS-экосистемы.
  3. Думай про «операции» — биллинг идёт по ним.
  4. Low-code заканчивается там, где начинается сложная логика, объём, низкая задержка или кастомные данные.
  5. Для AI-агентов с UI и контекстом смотри Dify/n8n/Flowise; для чат-ботов в Teams — Copilot Studio.
