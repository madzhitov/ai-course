ИИ для финансов: отчёты, анализ, прогнозы

Цель: применять ИИ в финансовом анализе — там, где это надёжно, и обходить там, где опасно Время: ~50 минут

Зачем тебе этот урок

Финансы — это анализ, документация, regulation, отчётность. ИИ ускоряет первые две. Третья и четвёртая — высокорисковые: галлюцинация в отчёте регулятору = штраф или хуже. Этот урок — карта применений с честными оценками рисков.

Аудит / compliance отчётность—❌ Регуляторный риск

2. Главное правило: ИИ — для текста, калькулятор — для чисел

LLM плохо считают арифметику. «Сколько 17% от 4534?» — GPT-5 ответит верно или почти верно. «Чистая прибыль за Q3 если выручка 432.5M, COGS 187.3M, opex 142.8M, амортизация 18.2M, налог 25%?» — может дать уверенно неправильный ответ. Чем больше чисел и шагов — тем выше шанс ошибки.

Решение: code execution. Все топ-модели сейчас могут запустить Python для расчётов:

  • ChatGPT с Code Interpreter / Advanced Data Analysis.
  • Claude Sonnet 4.5 с инструментом Code Execution (через API или в claude.ai).
  • Gemini 2.5 Pro в AI Studio.

Когда модель пишет код для расчёта, проверяй его, не саму цифру.

3. Анализ компании за 30 минут

Раньше: 2–3 дня. Сейчас:

  1. Скачай 10-K (US) или годовой отчёт.
  2. Загрузи в Claude (200k контекст вмещает целиком).
  3. Промпт:
10-K компании [name] за [year]: прикреплено.

Сделай инвестиционный memo:
1. Что компания делает (3 предложения).
2. Источники выручки с долями.
3. Главные KPI (5 шт) с динамикой 3 года.
4. Главные риски (Item 1A — Risk Factors).
5. Изменения в стратегии vs прошлый год.
6. Что management подчеркивает (MD&A).
7. Скрытые сигналы: что они НЕ обсуждают, что обсуждали раньше.
8. 5 уточняющих вопросов, которые я бы задал CFO.

Конкретика, не общие фразы.

Это даёт сильный первый pass. Дальше — ручная проверка цифр и углубление.

4. Извлечение данных из PDF

Финансовые PDF — кошмар. Таблицы, footnotes, разный layout. ИИ это решает:

Извлеки из этого PDF все P&L таблицы.

Формат: JSON массив {section, period, line_item, value, currency}.
Все значения в исходной валюте, не пересчитывай.
Указывай footnotes если есть.

Важно: всегда проверяй пару значений вручную. На сложных layouts модель путает ячейки.

5. Скрипты для расчётов

Это любимый пример с правильным применением ИИ. Запрос: «посчитай WACC». Промпт:

Напиши Python-скрипт, который считает WACC.

Входные: cost of equity, cost of debt, tax rate, market value of equity, market value of debt.

Скрипт должен:
1. Принимать значения как аргументы.
2. Выводить промежуточные значения (weight_equity, weight_debt, after_tax_cost_debt).
3. Иметь docstring с формулой.
4. Иметь pytest-тест на одном известном примере.

Получаешь рабочий скрипт за минуты. Один раз сделал — всю карьеру используешь.

6. Сравнительный анализ

Прикреплены 10-K трёх конкурентов: A, B, C.

Сравни:
1. Размер (выручка, активы, сотрудники).
2. Темп роста (3-year CAGR выручки).
3. Маржинальность (gross / operating / net).
4. Структура расходов.
5. R&D как % выручки.
6. Долговая нагрузка.
7. Капитальные затраты.

Таблица + 3 ключевых наблюдения, на что обратить внимание.

7. Документация инвестиционных решений

Investment committee требует memo на 5 страниц. ИИ делает первый драфт за минуты:

Инвестиционный тезис: [твой тезис, 2 абзаца]

Данные: [ключевые цифры из анализа]

Сделай 5-page IC memo:
1. Executive Summary (1 абзац).
2. Company Overview.
3. Investment Thesis (главные 3 точки).
4. Финансовый анализ (с цифрами).
5. Риски (минимум 5, с митигациями).
6. Valuation (диапазон + методы).
7. Catalysts (что должно сработать).
8. Структура сделки (предлагаемая).

Стиль: профессионально, конкретно, без воды.

8. Что НИКОГДА

  • Не торгуй по AI-сигналам без статистической валидации. Модели не предсказывают рынок.
  • Не цитируй AI как источник цифр. Всегда сверяй с оригиналом.
  • Не загружай MNPI (material non-public information) в публичный chat. Юридический риск, регуляторный риск.
  • Не используй AI для compliance-отчётности без human-in-the-loop. Цена ошибки слишком высокая.
  • Не делай valuation где AI «выбирает» multiples. Можешь использовать AI для расчёта DCF при заданных предпосылках — но предпосылки задаёт человек.

9. Регуляторное

  • SEC и FINRA (US) активно следят за AI в инвестбанках. «Хвалёные» AI-фонды получают вопросы. Документируй, как используешь AI.
  • EU AI Act: кредитный скоринг и страхование — высокорисковая категория. Документация и transparency обязательны.
  • Аудит-лог: для каждого AI-вспомогательного решения — что был промпт, что ответ, что человек решил.
  • MiFID II (EU) — best execution всё ещё ответственность человека, не AI.

10. Тонкости

  • Длинный контекст важен. 10-K = 200–400 страниц. Claude Sonnet 4.5 (200k стандарт, 1M в beta) вмещает несколько отчётов сразу. Gemini 2.5 Pro — 1M по умолчанию. Это даёт сильное преимущество против моделей с 32k.
  • Multimodal критичен для графиков. Если в PDF графики важны (а они важны) — GPT-5 или Gemini 2.5 Pro лучше понимают их визуально.
  • Цена анализа одной компании: ~$0.5–2 в API. Окупается с первого использования.
  • Финансовые модели с AI: GPT и Claude хорошо генерируют структуру Excel-модели + формулы (через Skills для xlsx), но конкретные предпосылки задаёшь ты.

11. Глоссарий

10-K / 10-Q

Годовой / квартальный отчёт публичной компании в SEC (US). Стандартизирован.

MD&A

Management Discussion & Analysis — часть отчёта, где руководство комментирует результаты. Источник скрытых сигналов.

Code Interpreter

Инструмент модели для запуска Python-кода. Главная защита от арифметических галлюцинаций.

MNPI

Material Non-Public Information — существенная непубличная информация. Утечка = инсайдерская торговля.

12. Практика (50 минут)

  1. Возьми 10-K любой публичной компании (sec.gov/edgar).
  2. Прогон через промпт «инвестиционный memo» в Claude Sonnet.
  3. Сверь 3 цифры в выводе с оригиналом — все верны?
  4. Сгенерируй Python-скрипт для одного финансового расчёта.
  5. Запиши в progress.md где ИИ дал реальное преимущество.

13. Проверь себя

1. Почему ИИ не доверяют арифметику?
LLM генерирует токен за токеном, не умножает на самом деле. Решение — code interpreter.

2. Где в финансах ИИ безопасен?
Суммаризация отчётов, извлечение данных, генерация memo, скрипты для расчётов, сравнительный анализ.

3. Где категорически нельзя?
Торговые сигналы без валидации, MNPI в публичных моделях, compliance-отчётность без human review.

4. Что обязательно при использовании ИИ в инвестбанке?
Аудит-лог, документация процесса, human-in-the-loop, compliance review.

14. Что должно остаться в голове

  1. ИИ — для текста, калькулятор/Python — для чисел. Code execution — must.
  2. 10-K анализ за 30 минут — реальный главный кейс.
  3. Сверяй цифры с оригиналом. Не цитируй AI как источник.
  4. MNPI — никогда в публичный chat.
  5. SEC / EU AI Act / MiFID II — учитывай документацию и transparency.
  6. Claude Sonnet 4.5 (200k–1M) и Gemini 2.5 Pro (1M) — главное оружие для длинных финансовых документов.
