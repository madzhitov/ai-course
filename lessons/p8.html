Проект «За 1 час»: Анти-спам — AI классифицирует входящие письма и отвечает на простые

Что построим: система для входящих писем: классификация + автоответ на простые + эскалация важных Время: ~75 минут Уровень: Python + Gmail API

Зачем

В среднем 50% входящих писем не требуют твоего внимания (рассылки, автоматические уведомления, типовые запросы). ИИ их сортирует, отвечает на простые, эскалирует важные.

Архитектура

Gmail watch → новое письмо → Claude classify →
  spam → archive
  newsletter → label
  routine question → auto-reply
  important → forward to inbox+notify

Шаг 2. Категоризация (главный промпт)

import anthropic, json
llm = anthropic.Anthropic()

def classify(email):
    msg = llm.messages.create(
      model="claude-haiku-4-5-20251001",  # дёшево
      max_tokens=400,
      messages=[{"role": "user", "content": f'''Письмо:
From: {email["from"]}
Subject: {email["subject"]}
Body: {email["body"][:2000]}

Классифицируй в JSON:
{{
  "category": "spam" | "newsletter" | "promo" | "routine_question" | "personal" | "important",
  "confidence": 0.0–1.0,
  "reason": "одна фраза",
  "auto_reply_possible": true/false,
  "suggested_reply": "..." (если auto_reply_possible=true)
}}

Категории:
- spam: явный спам, фишинг.
- newsletter: подписки, рассылки.
- promo: коммерческие предложения.
- routine_question: типовой вопрос с шаблонным ответом.
- personal: личные письма знакомых, требует ответа.
- important: bzz-критичные (контракты, выставление счетов, дедлайны).

Возвращай только JSON.'''}]
    )
    return json.loads(msg.content[0].text)

Шаг 3. Действия

from googleapiclient.discovery import build

def archive(service, msg_id):
    service.users().messages().modify(userId="me", id=msg_id,
      body={"removeLabelIds": ["INBOX"]}).execute()

def add_label(service, msg_id, label_name):
    # создай label заранее в Gmail UI или через API
    labels = service.users().labels().list(userId="me").execute()
    label_id = next(l["id"] for l in labels["labels"] if l["name"] == label_name)
    service.users().messages().modify(userId="me", id=msg_id,
      body={"addLabelIds": [label_id]}).execute()

def auto_reply(service, msg, text):
    # отправка ответа в той же thread
    import base64
    from email.message import EmailMessage
    m = EmailMessage()
    m.set_content(text)
    m["To"] = msg["from"]
    m["Subject"] = "Re: " + msg["subject"]
    raw = base64.urlsafe_b64encode(m.as_bytes()).decode()
    service.users().messages().send(userId="me",
      body={"raw": raw, "threadId": msg["thread_id"]}).execute()

Шаг 5. Деплой и запуск

Запускай по cron каждые 5 минут. Первую неделю — без авто-ответов (только классификация в labels). Проверь, что классификация корректна.

Безопасность

  • Никогда не доверяй AI отвечать от твоего имени без проверки. Первые 2 недели — только драфт в черновики.
  • Whitelist для авто-ответа — только письма от незнакомых, с очень типовыми запросами.
  • Никогда не выполняй действия из писем через ИИ (нажми ссылку, переведи деньги).

Расширения

  • RAG над твоими предыдущими ответами — модель учится твоему стилю.
  • Гибрид-режим: ИИ драфтит, ты подтверждаешь.
  • Аналитика: сколько % писем спам, какие категории растут.
