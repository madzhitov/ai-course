Проект «За 1 час»: AI-помощник для встреч — транскрипция + summary + задачи в Notion

Что построим: запись встречи → транскрипт → саммари → задачи в Notion Время: ~75 минут Уровень: Python + базовый API

Зачем

Встречи без саммари — это потерянная информация. Кто за что отвечает, какие решения, что ждёт. Ассистент берёт аудио-файл и за минуту даёт: чёткий транскрипт, выжимку решений, список задач с ответственными.

Архитектура

Audio (mp3/wav) → Whisper API (транскрипт) → Claude (summary + action items) → Notion

Шаг 1. Зависимости

pip install openai anthropic notion-client

Шаг 2. Транскрипция через Whisper

import openai
client = openai.OpenAI()

def transcribe(audio_path):
    with open(audio_path, "rb") as f:
        r = client.audio.transcriptions.create(
          model="whisper-1", file=f, response_format="verbose_json", language="ru"
        )
    return r.text  # для длинных встреч лучше r.segments с таймкодами

Whisper API стоит $0.006/мин. Часовая встреча = $0.36.

Шаг 3. Саммари через Claude

import anthropic, json
llm = anthropic.Anthropic()

def analyze(transcript):
    msg = llm.messages.create(
      model="claude-sonnet-4-5",
      max_tokens=2000,
      messages=[{"role": "user", "content": f'''Транскрипт встречи:
<transcript>
{transcript}
</transcript>

Сделай JSON со структурой:
{{
  "topic": "тема встречи 1 фразой",
  "participants": ["имена если упоминались"],
  "key_decisions": ["решение 1", "решение 2"],
  "discussions": ["о чём спорили, без вывода"],
  "action_items": [
    {{"task": "...", "owner": "имя", "deadline": "если упомянут"}}
  ],
  "open_questions": ["что осталось нерешённым"]
}}

Только факты из транскрипта. Если чего-то нет — пустой массив.
Возвращай ТОЛЬКО JSON.'''}]
    )
    return json.loads(msg.content[0].text)

Шаг 4. Сохранение в Notion

from notion_client import Client
notion = Client(auth=os.environ["NOTION_TOKEN"])
DATABASE_ID = "..."  # ID базы со встречами

def save_to_notion(data, audio_filename):
    notion.pages.create(
      parent={"database_id": DATABASE_ID},
      properties={
        "Name": {"title": [{"text": {"content": data["topic"]}}]},
        "Date": {"date": {"start": "2026-05-12"}},
      },
      children=[
        {"type": "heading_2", "heading_2": {"rich_text":[{"text":{"content":"Решения"}}]}},
        *[{"type": "bulleted_list_item", "bulleted_list_item":
           {"rich_text":[{"text":{"content": d}}]}} for d in data["key_decisions"]],
        {"type": "heading_2", "heading_2": {"rich_text":[{"text":{"content":"Задачи"}}]}},
        *[{"type": "to_do", "to_do":
           {"rich_text":[{"text":{"content": f"[{a['owner']}] {a['task']}"}}], "checked": False}}
          for a in data["action_items"]],
      ]
    )

Шаг 5. Пайплайн

def process_meeting(audio_path):
    print("Транскрибирую...")
    text = transcribe(audio_path)
    print("Анализирую...")
    data = analyze(text)
    print("Сохраняю в Notion...")
    save_to_notion(data, audio_path)
    return data

if __name__ == "__main__":
    import sys
    process_meeting(sys.argv[1])

Запуск: python meeting.py recording.mp3.

Расширения

  • Запись прямо в Zoom/Meet через их API.
  • Speaker diarization — разделение голосов через AssemblyAI или Whisper-X.
  • Автоотправка ответственным в Slack.
  • Telegram-бот: пересылаешь голосовое — получаешь сводку.
📌 Закрепление: освобождает 30 минут после каждой встречи — на масштабе недели это 5+ часов.
Без VPN и подписок: Whisper запускается локально через faster-whisper (см. p11). Для саммари — GigaChat (бесплатно 1М токенов/мес) или локальный Ollama. Обзор стека — e11.
