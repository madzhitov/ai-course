Claude Skills — пре-настроенные навыки

Цель: освоить Claude Skills — модульные «навыки», которые превращают Claude в специализированного помощника под конкретный домен Время: ~40 минут Источник: Anthropic «Introducing Skills» (октябрь 2025)

Зачем тебе этот урок

Skills — самая большая фича Claude осени 2025. Если MCP — это «как подключить Claude к внешним инструментам», то Skills — это «как Claude вызывает узко-специализированные способности из встроенной библиотеки или твоей собственной».

Зачем это нужно лично тебе:

  • Работа с Excel/PowerPoint/PDF — без копи-пастов через скриншоты, Claude напрямую читает и редактирует файлы.
  • Свои Skills под рутины — раз настроил, дальше Claude применяет автоматом.
  • Claude становится универсальным «не-кодовым» инструментом — типа Cursor, но для работы с документами.

1. Что такое Skill в одном абзаце

Skill — это именованный модуль возможностей с описанием «когда меня использовать». Claude видит список доступных Skills и сам решает, когда вызвать. Каждый Skill — это упакованные:

  • Инструкции (system-prompt'ы под задачу),
  • Tools (часто Computer Use или Code Execution),
  • Опционально — внешние ресурсы или файлы.

Звучит как функция или плагин — да, по идее. Но в отличие от MCP-сервера, Skill не требует своего сервера. Он живёт внутри Claude как пресет.

2. Чем Skills отличаются от MCP, Tools, Functions

ПодходЧто этоКогда использовать
Tool use / Function callingНизкоуровневое: ты описываешь функцию, Claude её вызываетСвои бэкенд-API, узкие действия
MCP-serverСтандартизированный сервер с tools и resourcesПодключение Claude к внешним системам (Notion, Linear, БД)
SkillГотовый «навык» с инструкциями и набором tools, упакованный Anthropic или сообществомДомен-специфичные задачи: Excel, PDF, презентации
Computer UseБазовая способность — управлять компьютером через скриншоты + кликиУниверсальный fallback для любого GUI

Можно думать так: Tools — это lego-кирпичики. MCP — сервер lego-кирпичиков. Skill — готовая lego-машинка под конкретную задачу.

3. Что Anthropic положил в первую партию Skills

На запуск (октябрь 2025) Anthropic выпустил несколько ключевых Skills:

📊 Excel skill

  • Открой .xlsx, проанализируй данные, сделай сводную таблицу — без выгрузки.
  • Применяй формулы, форматирование.
  • Создавай новые листы с диаграммами.

📑 PDF skill

  • Извлекай таблицы и текст из PDF (даже scanned, через OCR).
  • Заполняй PDF-формы.
  • Сливай или разбивай PDF.

🎨 PowerPoint skill

  • Создавай готовые .pptx из текстового описания.
  • Редактируй слайды на лету.
  • Применяй темы и шаблоны.

📄 Word skill

  • Создавай .docx с правильным форматированием.
  • Применяй стили, шрифты, заголовки.

🖼 Image/Vision skills

  • Анализ изображений с extraction в структурированный JSON.
  • Обрезка, ресайз, конвертация.

4. Как использовать Skill в Claude Desktop

Если у тебя Claude Pro/Team:

  1. Открой чат с Claude.
  2. Прикрепи файл (или вставь путь).
  3. Скажи задачу обычными словами: «Из этого Excel-файла сделай сводную таблицу по регионам и пришли назад .xlsx».
  4. Claude автоматически определит, что нужен Excel skill, вызовет его, выполнит — и пришлёт результирующий файл.

Никаких /команд явно вызывать не нужно — Claude сам решает по contextу.

5. Skills в API

Для разработчиков Skills доступны через Claude API. Пример включения Excel skill:

response = client.messages.create(
  model="claude-sonnet-4-5",
  max_tokens=4000,
  messages=[{"role": "user", "content": "Проанализируй прикреплённый Excel"}],
  tools=[{
    "type": "skill",
    "name": "excel"
  }],
  attachments=[...]
)

Можно подключать несколько Skills одновременно. Claude сам решит, какой использовать в каком моменте.

6. Свои собственные Skills

Anthropic дал возможность писать собственные Skills (пока beta). Skill = это:

  • SKILL.md — описание навыка для Claude (когда вызывать, что делать).
  • Инструменты — обычно Code Execution или MCP-серверы.
  • Опционально — примеры или базы знаний.

Пример SKILL.md для собственного Skill «расчёт unit-экономики»:

name: unit-economics
description: |
  Использовать когда пользователь приносит данные по продукту/сервису
  и хочет посчитать CAC, LTV, payback period.
  НЕ использовать для генеральной финансовой аналитики.

instructions: |
  1. Запроси CAC, среднюю выручку с клиента, churn rate.
  2. Если не хватает данных — спроси у пользователя.
  3. Посчитай через Code Execution, выведи в таблице.
  4. Дай интерпретацию: где red flag, где здорово.

tools:
  - code_execution

Положил в Anthropic Skills catalog (или загрузил локально) — Claude знает, как использовать.

7. Сценарии «купи Skill готовый» (Skills marketplace)

Anthropic запустил Skills catalog — там community-skills, готовые под конкретные домены:

  • Legal — анализ договоров по типу контракта
  • Medical — структурирование симптомов в SOAP-ноту
  • Finance — построение финмодели стартапа
  • Design — макеты в формате Figma JSON
  • Education — генерация структурированных учебных планов

Большинство бесплатны. Топовые могут стать платными в будущем.

8. Skills vs MCP — когда что

СценарийРешение
Работа с типовым форматом (Excel, PDF)Skill (готовый)
Доступ к твоей корпоративной БДMCP-сервер
Узкая бизнес-логика твоего продуктаСвой Skill
Интеграция с Notion / Linear / SlackMCP-сервер (часто готовый)
Расчёты на летуSkill code_execution или встроенный Code Interpreter

Можно комбинировать: Skill для расчётов + MCP для доступа к данным.

9. Тонкости и подводные камни

  • Skills не панацея. Если задача шире готового Skill — он не справится, потребует fallback на Computer Use.
  • Платформа важна. Excel/PowerPoint skills работают в Claude Desktop. В Claude.ai (веб) функционал ограниченнее.
  • Безопасность. Свои Skills могут содержать инструкции, которые модель будет применять «слепо». Принцип least privilege.
  • Версионирование. Skills эволюционируют — следи за обновлениями Anthropic.
  • Cost. Skill часто использует Code Execution или Computer Use под капотом — это дополнительные токены и время.

11. Практика (40 минут)

  1. Если у тебя Claude Pro/Team — открой Claude Desktop, прикрепи любой Excel-файл и спроси: «Сделай сводную таблицу по N столбцу».
  2. Попробуй сложить .pptx из текстового описания: «Создай презентацию на 5 слайдов про X».
  3. Открой официальные доки Skills.
  4. Идея на «следующий шаг»: напиши SKILL.md под одну рутину из своей работы.
  5. В progress.md запиши: какой Skill сэкономил бы тебе больше всего времени.

12. Проверь себя

1. Чем Skill отличается от MCP-сервера?
Skill — готовый «навык», упакованный с инструкциями. MCP — стандарт сервера для подключения внешних систем. Skill живёт внутри Claude; MCP — отдельный сервис.

2. Что в первой партии Skills от Anthropic?
Excel, PDF, PowerPoint, Word, Image/Vision — работа с типовыми форматами офисных документов.

3. Когда писать свой Skill, а когда брать готовый?
Готовый — если задача типовая (формат файла). Свой — если есть уникальная бизнес-логика.

4. Что такое Skills marketplace?
Каталог готовых Skills от Anthropic и сообщества по доменам (legal, medical, finance...).

13. Что должно остаться в голове

  1. Skill = упакованный «навык» Claude с инструкциями и tools. Готовый или свой.
  2. Skills ≠ MCP. Skill — готовая способность. MCP — протокол подключения.
  3. Первая партия: Excel, PDF, PowerPoint, Word, Image — типовые офисные форматы.
  4. Свой Skill = SKILL.md + tools (часто Code Execution).
  5. Skills catalog — каталог community-skills от Anthropic и сообщества.
  6. Можно комбинировать: Skill для логики + MCP для данных.
📌 Закрепление: Skills сильно меняют что значит «работать с Claude». Если ты ещё не пробовал — открой Claude Desktop и просто кинь Excel-файл с вопросом. Увидишь как меняется опыт.
