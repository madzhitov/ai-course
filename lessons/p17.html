Проект «За 1 час»: Конспект лекции из аудио — Whisper + Claude → markdown

Что построим: пайплайн «записал лекцию на телефон → получил структурированный конспект .md для Obsidian/Notion» Время: ~60 минут Уровень: Python базовый, чуть-чуть терпения с зависимостями

Зачем этот проект

Я ходил на двухчасовой воркшоп, записал на диктофон, пришёл домой и не знал, что с этим делать: переслушивать никто не будет, читать сырую транскрипцию на 25 тысяч слов — ещё хуже. Нужен нормальный конспект: тезисы, термины, ключевые идеи, цитаты.

Whisper расшифрует речь в текст. Но Whisper — глупый писарь: он не понимает, что важно. Это работа для Claude. Связка двух моделей даёт то, чего по отдельности нет: умный конспект из живой речи. Дальше я открываю файл в Obsidian, и материал готов для повторения.

Что в итоге будет

  • CLI-скрипт: python notes.py lecture.m4a → lecture.md рядом.
  • Расшифровка локально через faster-whisper (бесплатно, не требует интернета).
  • Структуризация через Claude: тезисы, термины с определениями, повторы (= важное), вопросы для повторения, цитаты.
  • Поддержка длинных записей (90+ минут) с разбиением на чанки и сшивкой.
  • Готовый markdown с фронтматтером, тегами, оглавлением — drag&drop в Obsidian.

Требования

  • Python 3.10+.
  • ffmpeg в системе (Whisper вызывает его для конвертации).
  • API-ключ Anthropic.
  • На Маке/Линуксе — 10 мин на установку, на Windows — 20.

Архитектура

аудио (m4a / mp3 / wav)
    ↓
faster-whisper (локально на CPU/GPU)
    ↓
сырой текст транскрипции
    ↓
разбиение на чанки по ~6000 слов (если длинная)
    ↓
Claude: каждый чанк → структурированный фрагмент
    ↓
сшивка фрагментов + общий саммари
    ↓
финальный .md файл

Шаг 2: транскрипция

Файл transcribe.py:

from faster_whisper import WhisperModel

def transcribe(audio_path, model_size="medium", language="ru"):
    """Возвращает полную транскрипцию и список сегментов (для таймкодов)."""
    # int8 — режим, который работает на CPU быстро и сносно по качеству
    model = WhisperModel(model_size, device="cpu", compute_type="int8")

    segments, info = model.transcribe(
        audio_path,
        language=language,
        beam_size=5,
        vad_filter=True,  # выкидывает паузы, ускоряет
    )

    full_text_parts = []
    segments_list = []

    for seg in segments:
        full_text_parts.append(seg.text)
        segments_list.append({
            "start": seg.start,
            "end": seg.end,
            "text": seg.text.strip(),
        })

    full_text = " ".join(full_text_parts).strip()
    return full_text, segments_list, info.duration

Чем больше модель — тем лучше качество, но медленнее. Моя рекомендация:

  • small — для технической речи на русском плохо, не советую.
  • medium — рабочий минимум для русского.
  • large-v3 — лучше всего, но тяжёлый. Имеет смысл для редких записей, где важно качество.

Шаг 3: разбиение на чанки

У Claude контекст большой, но впихивать туда 30к слов одной кучей — плохая идея: модель «теряет середину» и саммари получается рваный. Бьём на чанки по ~6000 слов с перекрытием.

def chunk_text(text, chunk_size_words=6000, overlap_words=300):
    """Делит длинный текст на куски с перекрытием для непрерывности."""
    words = text.split()
    if len(words) <= chunk_size_words:
        return [text]

    chunks = []
    start = 0
    while start < len(words):
        end = min(start + chunk_size_words, len(words))
        chunks.append(" ".join(words[start:end]))
        if end == len(words):
            break
        start = end - overlap_words

    return chunks

Перекрытие в 300 слов нужно, чтобы термин, упомянутый на границе кусков, не потерял контекст.

Шаг 4: структуризация через Claude

Это сердце проекта. Промпт спроектирован так, чтобы получить именно конспект, а не пересказ.

import os
from anthropic import Anthropic

client = Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))

STRUCTURE_PROMPT = """Перед тобой расшифровка фрагмента лекции (живая устная речь, может быть с оговорками и повторами).

Преврати это в качественный конспект на русском, в формате markdown.

ВАЖНО:
- Это конспект, а не пересказ. Выкидывай оговорки, «ну», «короче», повторы из-за того что лектор сбился.
- Сохраняй фактическую плотность. Если лектор привёл пример или число — сохрани его.
- ЕСЛИ лектор повторил одну мысль 2-3 раза в разных формулировках — это важно, помечай ⭐.
- Если лектор сказал что-то яркое цитатой — сохраняй в "Цитаты" дословно.

Структура ответа:

## Тезисы
- Тезис 1
- Тезис 2 ⭐ (если повторялось)
- ...

## Термины и определения
- **Термин** — определение, как лектор его дал
- ...

## Примеры и кейсы
- Описание примера/кейса в одном предложении
- ...

## Цитаты
> Точная цитата, если была яркая
> — без атрибуции, просто как цитата

## Вопросы для повторения
- Вопрос 1?
- Вопрос 2?
- (5-7 штук, проверяют главные идеи фрагмента)

Не добавляй преамбулы и заключений. Только структура выше."""


def structure_chunk(text):
    resp = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=4000,
        system=STRUCTURE_PROMPT,
        messages=[{"role": "user", "content": text}],
    )
    return resp.content[0].text.strip()

Шаг 5: сшивка чанков

Если чанков несколько — каждый структурируем отдельно, потом просим Claude слепить их в один документ без дублей.

MERGE_PROMPT = """Тебе дано N структурированных конспектов разных фрагментов одной лекции.
Слей их в единый цельный конспект:

- В каждой секции (Тезисы, Термины, Примеры, Цитаты, Вопросы) — объедини содержимое.
- Удали дубли (если один тезис встречается в двух фрагментах — оставь одну формулировку).
- Если термин определён в нескольких фрагментах — оставь самое полное определение.
- Тезисы упорядочи логически, а не по времени появления.
- В конце добавь секцию "## TL;DR" — 3-5 предложений общего смысла всей лекции.

Формат — тот же markdown."""


def merge_chunks(structured_chunks):
    if len(structured_chunks) == 1:
        return structured_chunks[0]

    joined = "\n\n---\n\n".join(
        f"### Фрагмент {i+1}\n{ch}" for i, ch in enumerate(structured_chunks)
    )

    resp = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=8000,
        system=MERGE_PROMPT,
        messages=[{"role": "user", "content": joined}],
    )
    return resp.content[0].text.strip()

Шаг 6: собираем CLI

Файл notes.py:

import sys
import os
from datetime import datetime
from pathlib import Path
from dotenv import load_dotenv

from transcribe import transcribe
from structure import structure_chunk, merge_chunks, chunk_text

load_dotenv()

def make_frontmatter(source_path, duration_sec):
    """Yaml-фронтматтер для Obsidian."""
    minutes = int(duration_sec // 60)
    return f"""---
source: {Path(source_path).name}
date: {datetime.now().strftime('%Y-%m-%d')}
duration_min: {minutes}
tags: [лекция, конспект, ai-generated]
---

"""


def main():
    if len(sys.argv) < 2:
        print("Usage: python notes.py ")
        sys.exit(1)

    audio = sys.argv[1]
    if not os.path.exists(audio):
        print(f"Файл не найден: {audio}")
        sys.exit(1)

    print(f"[1/4] Транскрибирую {audio}...")
    text, segments, duration = transcribe(audio, model_size="medium")
    print(f"      Готово: {len(text.split())} слов, {int(duration/60)} мин")

    # сохраняем сырую транскрипцию тоже — на всякий
    raw_path = Path(audio).with_suffix(".raw.txt")
    raw_path.write_text(text, encoding="utf-8")
    print(f"      Сырая транскрипция: {raw_path.name}")

    print("[2/4] Делю на чанки...")
    chunks = chunk_text(text, chunk_size_words=6000)
    print(f"      Чанков: {len(chunks)}")

    print("[3/4] Структурирую каждый чанк через Claude...")
    structured = []
    for i, ch in enumerate(chunks, 1):
        print(f"      Чанк {i}/{len(chunks)}...")
        structured.append(structure_chunk(ch))

    print("[4/4] Сшиваю...")
    final = merge_chunks(structured)

    out_path = Path(audio).with_suffix(".md")
    out_path.write_text(
        make_frontmatter(audio, duration) + final,
        encoding="utf-8"
    )
    print(f"\nГотово: {out_path}")


if __name__ == "__main__":
    main()

Расширения

  • Batch-обработка папки. Скрипт batch.py: пройти по папке ~/Recordings/, для каждого нового файла (которого ещё нет в .md) — прогнать пайплайн. Запускай раз в день cron-ом.
  • Автозапись с диктофона. На iOS — Shortcuts автоматически выгружает запись из «Диктофон» в iCloud Drive → автоматом подхватывается batch-скриптом → утром на компьютере уже готовый конспект.
  • Шеринг в Telegram-канал. После генерации .md — отправить первые 3000 символов (тезисы + TL;DR) в канал группы/команды. Все остальные участники получают саммари без необходимости слушать запись.
  • Спикер-диаризация. faster-whisper умеет отличать голоса (с pyannote.audio). Для интервью или подкаста — каждый абзац подписан «Спикер 1 / Спикер 2», в конспект попадает «Иванов считает X, Петров возражает Y». Сильно усложняет, но иногда стоит того.
  • Свой шаблон. Если ты учишься в вузе и нужен конспект «для семинара» — переписать промпт под формат предмета (формулы в LaTeX, схемы в mermaid). Один и тот же пайплайн адаптируется под любой формат через STRUCTURE_PROMPT.

Подводные камни

  • Качество транскрипции на русском. medium-модель путает имена, термины и аббревиатуры. «KPI» становится «кейпиай», «ChatGPT» — «чат-гэпэтэ». Один из способов борьбы — в промпт Claude передавать список ожидаемых терминов («лектор оперирует терминами: SQL, Kubernetes, latency») — он восстановит написание.
  • Шумная запись. Если писал на телефон в большом зале — будет много мусора. Перед транскрипцией стоит прогнать через любой денойзер (есть бесплатные онлайн), или использовать опцию vad_filter=True агрессивнее (см. параметры).
  • Длинные паузы / музыка. Whisper иногда «галлюцинирует» текст в местах тишины — пишет случайные фразы. vad_filter снижает риск, но не убирает. Если видишь в транскрипции странные фразы, не относящиеся к теме — это оно.
  • Стоимость API. Часовая лекция = ~10к слов = ~3 чанка по 6к. Каждый чанк = ~$0.03 на claude-sonnet-4-5. Плюс сшивка. Итого ~$0.15 за лекцию. Дёшево, но если планируешь обрабатывать сотни — лучше брать claude-haiku.
  • Whisper жрёт RAM. На large-v3 можно упереться в 4–8 ГБ оперативки. Если ноут слабый — оставайся на medium.
  • Этика записи. Если на лекции платный курс с NDA — подумай, ОК ли отправлять расшифровку в Anthropic. Локальная версия (Whisper + локальная LLM через Ollama) решает приватность, но качество структуризации заметно ниже.
