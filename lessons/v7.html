Урок v7. Вайб Клод Вам Дам: Claude как сэнсэй

Пояс: зелёный (база освоена, ставим вторую ногу) Время: ~40 минут Сэнсэй: Вам Дам (одна нога на КОД, вторая тянется к КЛОД)
🥋 Вам Дам кланяется и расставляет ноги. До сих пор мы говорили «Вайб КОД» — про вайбкодинг вообще, на любой модели. Сегодня я тяну вторую ногу. Она зовётся «Вайб КЛОД». А между ними сижу я — Вам Дам — на шпагате. Вайб Клод Вам Дам. Не бойся, мне не больно. Это поза силы. Поехали ставить вторую ногу.

Зачем тебе этот урок

Ты освоил базу: чистый лист, маленькие шаги, не воевать с моделью. Эти ката работают на любой модели — это первая нога шпагата, «Вайб КОД».

Но «вайбить вообще» и «вайбить с конкретным инструментом, который под это заточен» — разные ощущения. Сегодня ставим вторую ногу: вайбкодинг конкретно с Claude. У него есть две штуки, которые превращают вайб из «пишу промпт, жду, копирую код, вставляю, запускаю» в почти разговор: Artifacts и Claude Code. Описал — увидел — поправил репликой — повторил. Без копипасты, без переключений.

Этот урок — про то, как выглядит вайб, когда инструмент не мешает потоку, а несёт его. Шпагат сойдётся, когда обе ноги встанут ровно.

1. Почему Claude — хороший партнёр для вайба

Не реклама — конкретные свойства, которые важны именно для вайба:

  • Длинный контекст. Он держит в голове большой объём разговора и кода сразу. Для вайба это критично: ты ведёшь долгий диалог, накапливаешь правки — и не хочешь каждые пять реплик напоминать, о чём вы вообще.
  • Следует инструкциям. Сказал «не используй слайдеры» — он помнит это и через десять реплик. Дал антипример (привет, урок v5) — он держит границу. Для вайба, который весь на итерациях, это половина успеха.
  • Artifacts. Результат появляется прямо в чате как живой рабочий объект, а не как стена текста, которую надо куда-то копировать. Это и есть главный ускоритель вайба, и о нём — отдельно.

2. Artifacts: вайб без копипасты

Artifacts — это режим, в котором Claude выносит результат (код, страницу, приложение) в отдельную панель рядом с чатом и сразу его запускает. Ты описываешь — и в чате тут же появляется работающий UI или код, который можно потыкать. Не «вот тебе код, копируй и проверяй сам», а «вот тебе работающая штука, смотри».

Почему это идеально ложится на вайб. Вспомни обычный цикл без Artifacts: написал промпт → получил код → скопировал → создал файл → открыл в браузере → посмотрел → вернулся в чат → описал правку. Восемь шагов, и половина из них — возня, а не творчество.

С Artifacts цикл схлопывается: описал → увидел работающее прямо в чате → сказал репликой, что поправить → увидел обновлённое. Ты не выходишь из потока ни на секунду. Это вайб в чистом виде — поток намерения, не прерываемый технической вознёй.

Ты:    Сделай счётчик выпитой воды за день. Большая капля
       по центру, тапаешь — +1 стакан, под ней цифра.

Claude: [в панели Artifacts появляется работающий счётчик]

Ты:    Цель — 8 стаканов. Покажи прогресс: капля
       заполняется снизу по мере приближения к цели.

Claude: [Artifact обновляется, капля теперь заполняется]

Ты:    При достижении цели — короткая анимация и «Молодец».

Claude: [готово, тыкаешь и проверяешь прямо тут]

Заметь: ни одной копипасты, ни одного открытого файла. Только намерение и реплики. Подробно про Artifacts — в уроке c1 тропинки «Claude Deep Dive»; здесь нам важно одно: для вайба это лучший дом.

💡 Artifacts хорош для самодостаточных штук: страничка, виджет, мини-приложение, которое целиком живёт в браузере. Если задача упирается в реальный проект на диске с кучей файлов — это уже работа для Claude Code (секция 3).

3. Claude Code в режиме вайба

Artifacts живёт в чате. Но настоящий проект живёт у тебя на диске — десятки файлов, папки, зависимости. Туда Artifacts не дотянется. Туда идёт Claude Code — это Claude, который работает прямо в твоём терминале и имеет доступ к файлам проекта.

Вайб с Claude Code выглядит так: ты пишешь намерение словами — «добавь на сайт тёмную тему с переключателем в шапке» — и агент сам находит нужные файлы, правит их, при необходимости запускает проект, смотрит, что получилось, и чинит, если сломалось. Несколько файлов, несколько действий — по одной фразе от тебя.

Ты:    Добавь на сайт тёмную тему. Переключатель — иконкой
       в правом верхнем углу. Выбор пользователя запоминай.

Claude Code:
       — нашёл стили в styles.css
       — нашёл шапку в index.html
       — добавил переключатель и тёмную палитру
       — сохранил выбор в браузере
       — запустил, проверил: переключается, запоминается. Готово.

Это тот же вайб — намерение, не синтаксис, — но в масштабе целого проекта, а не одного файла в чате. Подробный разбор Claude Code — в уроке c5 тропинки «Claude Deep Dive». Здесь нам важна стойка: ты по-прежнему ведёшь намерением, просто инструмент теперь дотягивается до реального диска.

🥋 Вам Дам на шпагате между двух инструментов: «Левая нога — Artifacts, лёгкая, для разминки прямо в зале. Правая — Claude Code, тяжёлая, для боя на настоящем татами. Сила не в том, чтобы стоять на одной. Сила в том, чтобы знать, на какую перенести вес сейчас.»

4. Workflow вайба с Claude: один цикл, четыре такта

И в Artifacts, и в Claude Code вайб крутится по одному и тому же кругу. Запомни его как ката — он одинаков для обоих инструментов:

  1. Намерение. Скажи словами, что хочешь получить. Одно ясное предложение (привет, ката чистого листа из v2).
  2. Artifact / действие. Claude делает: рисует Artifact в чате или правит файлы на диске. Ты сразу видишь результат.
  3. Правка репликой. Не переписываешь промпт целиком — добавляешь одну фразу: «капля пусть заполняется снизу», «переключатель правее». Маленький шаг (привет, v2).
  4. Повтор. Возвращаешься к шагу 3, пока не сойдётся. Каждая реплика — один маленький шаг, не прыжок.

Весь прошлый опыт тропинки тут работает: намерение прежде формы, маленькие итерации, не воюй — перенаправляй. Claude просто убирает трение между тактами, чтобы круг крутился быстрее.

5. Когда Artifacts, а когда Claude Code

Главный навык этого урока — переносить вес на нужную ногу. Простое правило:

  • Быстрый UI-прототип, виджет, одна страница, проверка идеи — в чате нет проекта на диске, всё самодостаточно → Artifacts. Запустилось прямо в чате, потыкал, выбросил или сохранил.
  • Работа в реальном проекте на диске — много файлов, надо что-то добавить/починить в существующем коде, запускать локально → Claude Code. Агент дотягивается до файлов и сам наводит порядок.

Грубо: Artifacts — это разминка в зале, Claude Code — это бой на татами. Идею пощупать — Artifacts. Идею воплотить в живущем проекте — Claude Code. Часто маршрут такой: накидал и проверил концепт в Artifacts → понял, что годится → переносишь в реальный проект и доводишь через Claude Code.

7. Практика (30 минут): мини-приложение в Artifacts через вайб

Сегодня ставим вторую ногу руками. Собираем работающую штуку в Artifacts, ведя только намерением и репликами.

  1. (5 мин) Намерение. Выбери что-то крошечное и самодостаточное: счётчик воды, таймер для медитации, генератор случайного ужина из списка. Запиши одним предложением, что это и зачем (ката чистого листа из v2).
  2. (7 мин) Первый Artifact. Открой Claude, опиши намерение. Дождись, пока в панели Artifacts появится работающая версия. Потыкай её прямо в чате.
  3. (5 мин) Итерация 1. Дай одну правку репликой — что-то одно: цвет, размер, поведение кнопки. Не переписывай всё. Посмотри, как обновился Artifact.
  4. (5 мин) Итерация 2. Ещё одна реплика — добавь одну маленькую функцию (звук, цель, анимацию).
  5. (5 мин) Итерация 3. Третья реплика — финальный штрих. Заметь, что ты ни разу ничего не копировал и не открывал файлов.
  6. (3 мин) Вывод. Запиши одной строкой: чем этот цикл «намерение → Artifact → реплика» отличается по ощущению от обычного «промпт → копипаста код → запуск».

8. Проверь себя

1. Почему Claude — удобный партнёр именно для вайба?
Длинный контекст (держит весь долгий диалог), дисциплина в инструкциях (помнит запреты и антипримеры), и Artifacts — результат появляется работающим прямо в чате.

2. Что такое Artifacts и почему это идеально для вайба?
Режим, где Claude выносит результат в панель и сразу запускает. Цикл схлопывается до «описал → увидел работающее → поправил репликой», без копипасты и открывания файлов. Подробно — в уроке c1.

3. Чем Claude Code отличается от Artifacts?
Claude Code работает в терминале с доступом к файлам реального проекта: по одной фразе сам правит несколько файлов, запускает и чинит. Artifacts живёт в чате и хорош для самодостаточных штук. Подробно — в уроке c5.

4. Из каких четырёх тактов состоит цикл вайба с Claude?
Намерение → Artifact/действие → правка репликой → повтор. Один и тот же круг и для Artifacts, и для Claude Code.

5. Когда брать Artifacts, а когда Claude Code?
Artifacts — быстрый UI-прототип или виджет в чате, всё самодостаточно. Claude Code — работа в реальном проекте на диске с множеством файлов. Разминка в зале vs бой на татами.

9. Что должно остаться в голове

  1. «Вайб КЛОД» — вторая нога шпагата. База та же, инструмент заточен под вайб.
  2. Artifacts = вайб без копипасты. Описал → увидел работающее в чате → поправил репликой.
  3. Claude Code = вайб в реальном проекте. По фразе сам правит файлы на диске, запускает, чинит.
  4. Цикл один: намерение → результат → реплика → повтор. Маленькими шагами, как учили.
  5. Перенеси вес на нужную ногу. Artifacts — пощупать идею, Claude Code — воплотить в живущем проекте.
