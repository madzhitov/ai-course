Проект «За 1 час»: Авто-ревьюер pull request'ов на GitHub

Что построим: GitHub Action, оставляющий AI-ревью на каждый PR Время: ~75 минут Уровень: Python + GitHub Actions

Зачем

Качество кода + скорость ревью. AI-ревью не заменяет человека, но ловит 60–80% типичных проблем за минуты — и человек ревьюит уже отфильтрованный код.

Архитектура

PR opened/updated → GitHub Action triggered →
  fetch diff + context → Claude review →
  post comment on PR → request changes if critical issues

Шаг 1. Структура репозитория

your-repo/
├── .github/
│   └── workflows/
│       └── ai-review.yml
└── scripts/
    └── ai_review.py

Шаг 2. Скрипт ревью

# scripts/ai_review.py
import os, anthropic, requests, json

PR_NUM = int(os.environ["PR_NUMBER"])
REPO = os.environ["GITHUB_REPOSITORY"]
GH_TOKEN = os.environ["GITHUB_TOKEN"]
AN_KEY = os.environ["ANTHROPIC_API_KEY"]

def gh(method, path, **kw):
    return requests.request(method, f"https://api.github.com{path}",
      headers={"Authorization": f"Bearer {GH_TOKEN}", "Accept": "application/vnd.github+json"}, **kw)

# Получаем дифф PR
diff = gh("GET", f"/repos/{REPO}/pulls/{PR_NUM}",
          headers={"Accept": "application/vnd.github.v3.diff"}).text

pr = gh("GET", f"/repos/{REPO}/pulls/{PR_NUM}").json()
title = pr["title"]
body = pr["body"] or ""

# Промпт для ревью
client = anthropic.Anthropic(api_key=AN_KEY)
review = client.messages.create(
  model="claude-sonnet-4-5",
  max_tokens=2000,
  messages=[{"role": "user", "content": f'''Ты — старший разработчик. Делаешь code review.

Pull Request:
Title: {title}
Description: {body}

Diff:
{diff[:30000]}

Сделай review в формате:

## Сводка
1–2 предложения о PR.

## Критические проблемы (если есть)
- Только реальные баги, безопасность, performance.

## Замечания
- Стиль, читаемость, тесты.

## Положительное
- Что хорошо сделано.

## Verdict
"approve" / "request_changes" / "comment"

Только обоснованные замечания. Не придирайся к стилю если он соответствует окружению.'''}]
).content[0].text

# Постим комментарий
gh("POST", f"/repos/{REPO}/issues/{PR_NUM}/comments",
   json={"body": "🤖 **AI Review** (Claude Sonnet)\n\n" + review})

# Если verdict == request_changes, оставим review с REQUEST_CHANGES
if "request_changes" in review.lower():
    gh("POST", f"/repos/{REPO}/pulls/{PR_NUM}/reviews",
       json={"event": "REQUEST_CHANGES", "body": "См. AI-комментарий выше"})

Шаг 3. GitHub Action

# .github/workflows/ai-review.yml
name: AI Review
on:
  pull_request:
    types: [opened, synchronize]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.11' }
      - run: pip install anthropic requests
      - run: python scripts/ai_review.py
        env:
          PR_NUMBER: ${{ github.event.pull_request.number }}
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}

Шаг 4. Setup в репозитории

  1. Settings → Secrets → New secret: ANTHROPIC_API_KEY.
  2. Закоммить файлы.
  3. Открой тестовый PR — Action запустится автоматически.

Шаг 5. Улучшения

  • Inline-комменты на конкретных строках через POST /repos/{repo}/pulls/{n}/comments с line + path.
  • Контекст соседних файлов — добавь импорты, чтобы модель понимала зависимости.
  • Конфиг через .ai-review.yml: какие папки игнорировать, какие правила.
  • Двухмодельная стратегия: Haiku для быстрого первичного прохода, Sonnet — для критичных PR.
  • Promtbook — храните в репо подсказки под типы PR (security, refactor, feature).

Стоимость

Один PR со средним диффом 5k токенов = $0.02–0.04 на ревью. На 100 PR/мес = $2–4. Дешевле кофе.

Чего НЕ делать

  • Не доверяй финальный approve AI — должен быть человек.
  • Не передавай в Claude приватные/чувствительные репо без enterprise-договора (или используй self-hosted Sonnet через AWS Bedrock).
  • Не игнорируй усталость ревьюеров — если AI генерирует слишком много шума, выключай.
📌 Закрепление: AI-ревью — это «как иметь второго senior'a в команде, который доступен 24/7 за $5/мес». Не заменяет человека, но усиливает.
