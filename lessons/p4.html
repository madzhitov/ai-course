Проект «За 1 час»: Анализ счетов и чеков через Claude Vision

Что построим: приложение, превращающее фото чека в строку Google Sheets с расходами Время: ~60 минут Уровень: Python + базовый API

Зачем

Каждый чек — это потенциальная строка в семейном бюджете, которую никто не заполнит вручную. Раньше нужен был OCR + классификатор + ручная разметка. Сейчас — один вызов Claude с картинкой, и получаешь структурированный JSON.

Что узнаешь

  • Multimodal Claude API (vision).
  • Structured output: JSON по инструкции в промпте (для гарантированного JSON в API Claude есть Structured Outputs, параметр output_config.format).
  • Google Sheets API.
  • Простой web-UI на Streamlit для загрузки.

Архитектура

Streamlit upload → Claude Sonnet (vision + JSON) → Google Sheets append

Шаг 1. Установка

pip install anthropic streamlit gspread

Шаг 2. Промпт для распознавания

EXTRACT_PROMPT = """
Перед тобой фото чека. Извлеки данные в JSON:
{
  "store": "название магазина",
  "date": "YYYY-MM-DD",
  "total": число,
  "currency": "RUB" | "USD" | ...,
  "category": "groceries" | "restaurant" | "transport" | "other",
  "items": [{"name": "...", "price": число, "quantity": число}]
}

Если что-то не видно — null. Не придумывай. Возвращай ТОЛЬКО JSON, без пояснений.
"""

Шаг 3. Vision-вызов

import anthropic, base64, json
client = anthropic.Anthropic()

def analyze_receipt(image_bytes):
    img64 = base64.b64encode(image_bytes).decode()
    # тип должен совпадать с реальным форматом файла, иначе API вернёт ошибку 400
    media_type = "image/png" if image_bytes[:8] == b"\x89PNG\r\n\x1a\n" else "image/jpeg"
    msg = client.messages.create(
      model="claude-sonnet-5-5",
      max_tokens=1024,
      messages=[{
        "role": "user",
        "content": [
          {"type": "image", "source": {"type": "base64", "media_type": media_type, "data": img64}},
          {"type": "text", "text": EXTRACT_PROMPT}
        ]
      }]
    )
    return json.loads(msg.content[0].text)

Шаг 4. Google Sheets

Создай Service Account в console.cloud.google.com, скачай credentials.json, share Google Sheet с email сервиса.

import gspread
gc = gspread.service_account(filename="credentials.json")
sheet = gc.open("My Expenses").sheet1

def append_to_sheet(data):
    sheet.append_row([data["date"], data["store"], data["category"],
                      data["total"], data["currency"],
                      ", ".join(i["name"] for i in data["items"])])

Шаг 5. Streamlit UI

import streamlit as st
st.title("Receipt → Sheet")
uploaded = st.file_uploader("Загрузи фото чека", type=["jpg","png","jpeg"])
if uploaded:
    st.image(uploaded)
    if st.button("Обработать"):
        with st.spinner("Анализирую..."):
            data = analyze_receipt(uploaded.read())
            st.json(data)
            append_to_sheet(data)
            st.success("Записано в таблицу!")

Запускай: streamlit run app.py.

Шаг 6. Расширения

  • Telegram-бот вместо Streamlit: пересылаешь фото чека → запись в Sheets.
  • Анализ за месяц: отдельный скрипт читает Sheet и через Claude генерирует отчёт.
  • OCR в банковских выписках — то же самое, но с PDF.
  • Категоризация по обучаемому списку — fine-tune категорий под себя.
