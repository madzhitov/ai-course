Проект «За 1 час»: Self-hosted Perplexity — Q&A с поиском по твоим данным

Что построим: веб-приложение, которое ищет по твоим документам + интернету и отвечает с цитатами Время: ~90 минут Уровень: Python + urok 14 (RAG)

Зачем

Perplexity делает 3 вещи: ищет в сети, читает результаты, отвечает с цитатами. Своя версия даёт: приватность + поиск по твоим данным + контроль модели.

Архитектура

FastAPI ─ user query
          ↓
    [parallel]: RAG(my docs) + web_search(SerpAPI/Tavily)
          ↓
    Claude with sources → answer with citations
          ↓
    Streamlit/Next.js UI

pip install anthropic chromadb tavily-python fastapi uvicorn streamlit

Шаг 2. Векторная база с твоими доками (15 мин)

import chromadb, anthropic, os
from pathlib import Path

client = chromadb.PersistentClient(path="./db")
coll = client.get_or_create_collection("docs")

# Используем Claude эмбеддинги через OpenAI (Anthropic не делает эмбеддинги — берём voyageai или openai)
import openai
emb_client = openai.OpenAI()

def embed(texts):
    return [e.embedding for e in emb_client.embeddings.create(
      model="text-embedding-3-small", input=texts).data]

def index_docs(folder):
    docs, ids = [], []
    for f in Path(folder).rglob("*.md"):
        docs.append(f.read_text())
        ids.append(str(f))
    coll.add(documents=docs, embeddings=embed(docs), ids=ids)

Шаг 3. Web search (Tavily — 10 мин)

Tavily — search API для AI. Получи ключ на tavily.com (бесплатно 1k/мес).

from tavily import TavilyClient
tav = TavilyClient(api_key=os.environ["TAVILY_KEY"])

def web_search(query):
    r = tav.search(query=query, max_results=5, include_raw_content=True)
    return [{"url": x["url"], "title": x["title"], "content": x["raw_content"][:2000]} for x in r["results"]]

Шаг 4. Поиск + ответ

llm = anthropic.Anthropic()

def answer(query):
    # Локальные документы
    q_emb = embed([query])[0]
    local = coll.query(query_embeddings=[q_emb], n_results=3)
    local_docs = [{"source": local["ids"][0][i], "content": d}
                  for i,d in enumerate(local["documents"][0])]

    # Веб
    web_docs = web_search(query)

    sources = local_docs + web_docs

    # Промпт с источниками
    src_text = "\n\n".join(f"[{i+1}] {s.get('source') or s.get('url')}:\n{s['content'][:1000]}"
                            for i, s in enumerate(sources))

    msg = llm.messages.create(
      model="claude-sonnet-4-5",
      max_tokens=1500,
      messages=[{"role": "user", "content": f'''Источники:
{src_text}

Вопрос: {query}

Ответь, опираясь только на источники. После каждого утверждения — номер источника в [квадратных скобках].
Если в источниках нет ответа — скажи "не нашёл".
'''}]
    )
    return {"answer": msg.content[0].text, "sources": sources}

Шаг 5. FastAPI + UI (20 мин)

from fastapi import FastAPI
app = FastAPI()

@app.post("/ask")
def ask(query: str):
    return answer(query)

Простой UI на Streamlit:

import streamlit as st, requests
st.title("Мой Perplexity")
q = st.text_input("Вопрос:")
if q:
    with st.spinner("Ищу..."):
        r = requests.post("http://localhost:8000/ask", params={"query": q}).json()
        st.markdown(r["answer"])
        st.divider()
        st.caption("Источники:")
        for i, s in enumerate(r["sources"]):
            st.markdown(f"**[{i+1}]** {s.get('source') or s.get('url')}")
