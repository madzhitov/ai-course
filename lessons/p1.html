Проект «За 1 час»: Telegram-бот для саммари длинных переписок

Что построим: бот, в который пересылаешь чат — получаешь TL;DR Время: ~60 минут Уровень: базовый Python + урок 6 курса

Зачем этот проект

Самый частый запрос «зачем мне ИИ»: «у меня по 1000 непрочитанных сообщений в каждом чате». Этот бот решает: пересылаешь ему фрагмент длинной переписки → получаешь краткую выжимку: о чём говорили, какие решения, что от тебя ждут.

Это полезный личный инструмент + хороший первый pet-проект. После него ты понимаешь, как делается весь стек: Telegram Bot API → backend на Python → вызов LLM → ответ.

Что узнаешь

  • Как создать бота в Telegram через BotFather.
  • Базовая работа с aiogram (фреймворк для TG-ботов на Python).
  • Передача длинного текста в LLM с правильным промптом для саммари.
  • Деплой бесплатно на Railway / Render / Fly.io.

Что понадобится

  • Python 3.10+.
  • API-ключ OpenAI или Anthropic (см. урок 6).
  • Telegram-аккаунт.
  • ~60 минут.

Шаг 1. Создаём бота через BotFather (5 минут)

  1. В Telegram найди @BotFather.
  2. /newbot → имя для отображения (например, «Summary Bot»).
  3. Username — должен оканчиваться на _bot (например, my_summary_bot).
  4. Получишь токен вида 1234567:AABBccDDeeFFgg. Сохрани в .env.

Шаг 2. Настройка проекта

mkdir summary-bot && cd summary-bot
python3 -m venv venv && source venv/bin/activate
pip install aiogram openai python-dotenv

Создай .env:

TG_TOKEN=1234567:AABBccDDeeFFgg
OPENAI_API_KEY=sk-...

Шаг 3. Минимальный бот

Файл bot.py:

import os
import asyncio
from dotenv import load_dotenv
from aiogram import Bot, Dispatcher, F
from aiogram.types import Message
from aiogram.filters import Command
from openai import OpenAI

load_dotenv()
bot = Bot(token=os.getenv("TG_TOKEN"))
dp = Dispatcher()
client = OpenAI()

SUMMARY_PROMPT = """Ты пресс-секретарь. Перед тобой переписка из мессенджера.

Сделай краткое summary в формате:

📌 ТЕМЫ (что обсуждали, 1-3 пункта)

✅ РЕШЕНИЯ (что решили, что-то конкретное)

⚠️ ВОПРОСЫ К НАМ (что ждут от меня лично — если упоминается)

📅 ДАТЫ И ДЕДЛАЙНЫ (если есть)

Будь краток. Не воды, только факты. Если переписка пустая или
бессмысленная — скажи прямо."""


@dp.message(Command("start"))
async def cmd_start(message: Message):
    await message.answer(
        "Привет! Перешли мне или вставь любую длинную переписку — "
        "я сделаю выжимку. Работает с пересылкой нескольких сообщений подряд."
    )


@dp.message(F.text)
async def summarize(message: Message):
    text = message.text
    if len(text) < 100:
        await message.answer("Слишком короткое для саммари. Минимум 100 символов.")
        return

    await message.answer("⏳ Делаю саммари...")

    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[
            {"role": "system", "content": SUMMARY_PROMPT},
            {"role": "user", "content": text}
        ],
        temperature=0.3,
        max_tokens=600
    )

    summary = response.choices[0].message.content
    await message.answer(summary, parse_mode="Markdown")


async def main():
    await dp.start_polling(bot)


if __name__ == "__main__":
    asyncio.run(main())

Запуск:

python bot.py

Перешли в бот любую переписку — увидишь саммари.

Шаг 4. Улучшения (по желанию)

Поддержка пересылки нескольких сообщений

Если переслать 5 сообщений — каждое прилетит отдельно. Лучше склеить:

from collections import defaultdict
from datetime import datetime

# буфер: user_id → список (время, текст)
forward_buffer = defaultdict(list)

@dp.message(F.text)
async def collect(message: Message):
    user_id = message.from_user.id
    forward_buffer[user_id].append((datetime.now(), message.text))

    # ждём 2 секунды без новых сообщений
    await asyncio.sleep(2)

    # если за это время пришли ещё — выходим (тот вызов отработает)
    last_time = forward_buffer[user_id][-1][0]
    if (datetime.now() - last_time).total_seconds() < 1.5:
        return

    # склеиваем и обрабатываем
    full_text = "\n\n".join([t for _, t in forward_buffer[user_id]])
    forward_buffer[user_id] = []

    if len(full_text) < 100:
        await message.answer("Слишком короткое.")
        return

    # ... тот же код саммари ...

Лимит длины

OpenAI ограничивает контекст 128k токенов. На bot.py 100k символов = ~30k токенов — пройдёт. Но если кто-то пришлёт книгу — упрётся. Добавь:

if len(text) > 200_000:
    await message.answer("Текст слишком длинный (>200к знаков). Раздели на части.")
    return

Стоимость

На gpt-4o-mini одно саммари 5к слов = ~$0.001. 1000 саммари в месяц = $1. Очень дёшево.

Защита от спама

Если выкладываешь публично — добавь rate limit:

from time import time

Шаг 5. Деплой бесплатно

Бот пока работает только пока твой ноут включён. Чтобы 24/7 — деплой:

Вариант 1: Railway (~5 минут)

  1. Залогинься на railway.app через GitHub.
  2. New Project → Deploy from GitHub repo (нужно сначала закоммитить).
  3. Variables: добавь TG_TOKEN и OPENAI_API_KEY.
  4. Готово. $5 free credit на старт, потом ~$1–3/мес.

Вариант 2: Render free tier

Бесплатно, но засыпает после 15 минут без активности — для бота не очень.

Вариант 3: Дешёвый VPS

Hetzner CX11 = €4/мес, поднимаешь как systemd-сервис. Самый предсказуемый вариант.

Что дальше — варианты развития

  • Поддержка голосовых через Whisper API.
  • Несколько режимов: «summary», «найди задачи мне», «оцени тон».
  • Кеширование (одинаковый текст → не платить дважды).
  • Многоязычная детекция и саммари на языке оригинала.
  • Сохранение истории саммари в SQLite.
  • Деплой как Telegram Mini App с веб-интерфейсом.
