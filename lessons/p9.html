Проект «За 1 час»: Семантический поиск по своему Telegram-каналу или чату

Что построим: поиск «по смыслу» по экспорту своего Telegram-канала или чата Время: ~60 минут Уровень: Python + urok 8 (эмбеддинги)

Зачем

В Telegram стандартный поиск — по точным словам. «Где я писал про оптимизацию баз?» — если ты писал «ускорил Postgres», не найдёт. Semantic search решает.

Что узнаешь

  • Экспорт чата/канала из Telegram.
  • Парсинг JSON в чанки.
  • Embeddings + ChromaDB.
  • Простой CLI или TG-бот для поиска.

Шаг 1. Экспорт чата (5 мин)

Telegram Desktop → Settings → Advanced → Export Telegram data → выбери чат → формат JSON. Получишь result.json.

Шаг 2. Парсинг

import json
data = json.load(open("result.json"))
messages = []
for m in data["messages"]:
    if m["type"] != "message": continue
    text = m["text"] if isinstance(m["text"], str) else "".join(
      t["text"] if isinstance(t, dict) else t for t in m["text"]
    )
    if len(text) < 20: continue  # пропускаем «ок», «👍»
    messages.append({"id": m["id"], "date": m["date"], "from": m.get("from"), "text": text})

Шаг 3. Эмбеддинги в ChromaDB

import chromadb, openai
client = chromadb.PersistentClient(path="./tg_db")
coll = client.get_or_create_collection("messages")
emb_client = openai.OpenAI()

def embed_batch(texts):
    r = emb_client.embeddings.create(model="text-embedding-3-small", input=texts)
    return [e.embedding for e in r.data]

# Батчами по 100
for i in range(0, len(messages), 100):
    batch = messages[i:i+100]
    coll.add(
      ids=[str(m["id"]) for m in batch],
      documents=[m["text"] for m in batch],
      embeddings=embed_batch([m["text"] for m in batch]),
      metadatas=[{"date": m["date"], "from": m["from"] or ""} for m in batch]
    )
    print(f"Indexed {i+len(batch)} / {len(messages)}")

Стоимость: 10k сообщений × средняя длина 200 токенов = 2M токенов × $0.02/1M = $0.04. Один раз.

Шаг 4. Поиск

def search(query, k=5):
    q_emb = embed_batch([query])[0]
    r = coll.query(query_embeddings=[q_emb], n_results=k)
    for i, doc in enumerate(r["documents"][0]):
        meta = r["metadatas"][0][i]
        print(f"[{meta['date']}] {meta['from']}: {doc[:200]}...\n")

search("оптимизация баз данных")

Шаг 5. TG-бот для поиска

from aiogram import Bot, Dispatcher, types
import asyncio

bot = Bot(token=os.environ["TG_BOT_TOKEN"])
dp = Dispatcher()

@dp.message()
async def handle(message: types.Message):
    q_emb = embed_batch([message.text])[0]
    r = coll.query(query_embeddings=[q_emb], n_results=5)
    reply = ""
    for i, doc in enumerate(r["documents"][0]):
        meta = r["metadatas"][0][i]
        reply += f"**{meta['date']}** ({meta['from']}):\n{doc[:300]}\n\n"
    await message.answer(reply, parse_mode="Markdown")

asyncio.run(dp.start_polling(bot))

Расширения

  • Q&A — поверх поиска прикручиваешь Claude, который отвечает на вопрос по найденным сообщениям.
  • Несколько чатов сразу — добавь поле chat_name в metadata.
  • Инкрементальный апдейт — раз в день добавляешь новые сообщения через Telethon (TG-клиент-API).
  • Фильтр по дате/автору через метаданные.
