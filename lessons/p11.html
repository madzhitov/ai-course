Проект «За 1 час»: Голосовой AI-ассистент — Whisper + Claude + TTS на твоём железе

Что построим: микрофон → распознавание → Claude → озвучка ответа Время: ~90 минут Уровень: Python средний + уроки 6, 7 курса

Что в итоге будет

Запускаешь скрипт. Нажимаешь Enter — говоришь в микрофон. Отпускаешь Enter — Whisper переводит речь в текст. Текст летит в Claude. Ответ Claude озвучивается через edge-tts и проигрывается. Получается полноценный голосовой ассистент, который работает локально (кроме самого Claude API и edge-tts) — без подписок на Alexa, Siri и прочего.

На выходе — около 250 строк Python-кода и реальный voice agent, к которому можно прикрутить любую логику: таймеры, списки покупок, погоду, управление умным домом, что угодно.

Архитектура

[микрофон / sounddevice]
        ↓ (PCM 16kHz mono)
[faster-whisper]
        ↓ (текст реплики)
[Anthropic Claude API]
        ↓ (текст ответа)
[edge-tts → MP3]
        ↓
[simpleaudio / afplay → колонки]

Между шагами — простой синхронный pipeline. Сначала делаем работающую версию, потом обсудим, где можно распараллелить.

Требования

  • Python 3.10+ (у меня 3.11.7 на macOS, проверял также на Ubuntu 22.04).
  • Микрофон (встроенный в ноут подойдёт).
  • API-ключ Anthropic (sk-ant-...) — см. урок 6.
  • Интернет (для Claude и edge-tts, Whisper работает офлайн).
  • ~2 GB места на диске под модель Whisper (small/medium).

Шаг 2. Запись с микрофона по нажатию Enter

Простейший паттерн «push-to-talk без удержания»: нажал Enter — пошла запись, нажал Enter ещё раз — стоп. Так удобнее, чем VAD на старте.

Файл record.py:

import sounddevice as sd
import numpy as np
import threading
import queue

SAMPLE_RATE = 16000  # Whisper хочет 16kHz mono


def record_until_enter() -> np.ndarray:
    """Пишет с микрофона, пока пользователь не нажмёт Enter второй раз."""
    print("🎙  Говори (нажми Enter, чтобы остановить)...")

    q: queue.Queue = queue.Queue()
    stop_flag = threading.Event()

    def callback(indata, frames, time, status):
        if status:
            print(status, flush=True)
        q.put(indata.copy())

    def wait_for_enter():
        input()
        stop_flag.set()

    threading.Thread(target=wait_for_enter, daemon=True).start()

    chunks = []
    with sd.InputStream(samplerate=SAMPLE_RATE, channels=1,
                        dtype="float32", callback=callback):
        while not stop_flag.is_set():
            try:
                chunks.append(q.get(timeout=0.1))
            except queue.Empty:
                continue

    audio = np.concatenate(chunks, axis=0).flatten()
    print(f"   записано {len(audio)/SAMPLE_RATE:.1f} сек")
    return audio


if __name__ == "__main__":
    input("Нажми Enter, чтобы начать запись...")
    audio = record_until_enter()
    import soundfile as sf
    sf.write("test.wav", audio, SAMPLE_RATE)
    print("сохранено в test.wav")

Запусти отдельно — убедись, что в test.wav слышно тебя. Если тишина — у меня было такое на macOS, пока не выдал Terminal'у разрешение «Микрофон» в System Settings → Privacy.

Шаг 3. Whisper для распознавания

Беру faster-whisper вместо оригинального openai-whisper — в 4 раза быстрее на CPU за счёт CTranslate2, при том же качестве. Модель small весит ~480 MB и нормально разбирает русский. Если есть GPU — бери medium или large-v3.

Файл asr.py:

from faster_whisper import WhisperModel
import numpy as np

# Загружаем модель один раз при старте. Не делай это в каждом вызове —
# инициализация ~3 сек, после неё inference 0.5-2 сек на 10 сек речи.
_model = WhisperModel(
    "small",                  # tiny / base / small / medium / large-v3
    device="cpu",             # на Mac M1+ можно "auto", оно подхватит Metal
    compute_type="int8"       # для CPU самый быстрый, на GPU - "float16"
)


def transcribe(audio: np.ndarray, language: str = "ru") -> str:
    """Получает 16kHz mono float32 numpy array, возвращает текст."""
    segments, info = _model.transcribe(
        audio,
        language=language,
        beam_size=5,
        vad_filter=True,                  # выкидывает молчание
        vad_parameters={"min_silence_duration_ms": 500}
    )
    text = " ".join(seg.text.strip() for seg in segments)
    return text.strip()


if __name__ == "__main__":
    import soundfile as sf
    audio, sr = sf.read("test.wav", dtype="float32")
    assert sr == 16000, f"ожидаю 16kHz, получил {sr}"
    print("распознано:", transcribe(audio))

Прогони на test.wav. У меня на M2 Air медиана ~1.2 сек на 8 сек речи на модели small с CPU. На tiny ещё быстрее, но русский разбирает заметно хуже — путает похожие слова.

Шаг 4. Claude как «мозг»

Тут ничего нового по сравнению с уроком 6 — просто оборачиваем вызов в функцию и держим короткую историю диалога, чтобы агент не забывал контекст.

Файл llm.py:

import os
from anthropic import Anthropic

client = Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])

SYSTEM = """Ты голосовой ассистент. Тебя слышат, не читают —
поэтому отвечай коротко (2-4 предложения), без списков, заголовков,
кода и markdown. Если просят сделать что-то конкретное (таймер,
запись в список, погода) — выполни команду через инструменты.
Если нужна уточняющая информация — задай один короткий вопрос."""


class Brain:
    def __init__(self):
        self.history: list[dict] = []

    def reply(self, user_text: str) -> str:
        self.history.append({"role": "user", "content": user_text})
        # Держим только последние 10 реплик, чтобы не раздувать контекст
        msgs = self.history[-10:]

        resp = client.messages.create(
            model="claude-3-5-sonnet-latest",
            max_tokens=400,
            system=SYSTEM,
            messages=msgs,
        )
        answer = resp.content[0].text.strip()
        self.history.append({"role": "assistant", "content": answer})
        return answer

Шаг 5. TTS через edge-tts

Edge-tts — это бесплатная обёртка над голосами Microsoft Edge Read Aloud. Качество — на уровне платных сервисов, голосов русских много (ru-RU-DmitryNeural, ru-RU-SvetlanaNeural), и не нужно никаких ключей. Юридически — серая зона, для личного использования нормально, в production я бы взял что-то официальное (ElevenLabs / Yandex SpeechKit).

Файл tts.py:

import asyncio
import tempfile
import subprocess
import platform
import edge_tts

VOICE = "ru-RU-DmitryNeural"


async def _synthesize(text: str, out_path: str):
    communicate = edge_tts.Communicate(text, VOICE)
    await communicate.save(out_path)


def speak(text: str):
    """Синтезирует и проигрывает речь синхронно."""
    with tempfile.NamedTemporaryFile(suffix=".mp3", delete=False) as f:
        out_path = f.name

    asyncio.run(_synthesize(text, out_path))

    system = platform.system()
    if system == "Darwin":
        subprocess.run(["afplay", out_path], check=False)
    elif system == "Linux":
        subprocess.run(["mpg123", "-q", out_path], check=False)
    elif system == "Windows":
        # самое простое - через PowerShell
        subprocess.run([
            "powershell", "-c",
            f"(New-Object Media.SoundPlayer '{out_path}').PlaySync();"
        ], check=False)


if __name__ == "__main__":
    speak("Привет, я твой голосовой ассистент. Готов помочь.")

На Linux заранее поставь sudo apt install mpg123. На Mac afplay идёт в коробке. На Windows PowerShell играет WAV из коробки, но не MP3 — для надёжности можно поставить pip install playsound==1.2.2 и проигрывать через него.

Шаг 6. Собираем всё вместе

Файл main.py — это весь pipeline:

from record import record_until_enter
from asr import transcribe
from llm import Brain
from tts import speak


def main():
    brain = Brain()
    print("Голосовой ассистент готов. Скажи 'выход' чтобы завершить.\n")

    while True:
        input("⏎ Enter — говорить, Ctrl+C — выход.")

        audio = record_until_enter()
        if len(audio) < 16000 * 0.3:   # меньше 0.3 секунды - игнор
            print("слишком коротко, пропускаю\n")
            continue

        user_text = transcribe(audio)
        if not user_text:
            print("ничего не распознал\n")
            continue
        print(f"👤 ты: {user_text}")

        if user_text.lower().strip(".,!? ") in {"выход", "стоп", "пока"}:
            speak("Пока!")
            break

        answer = brain.reply(user_text)
        print(f"🤖 Claude: {answer}\n")
        speak(answer)


if __name__ == "__main__":
    try:
        main()
    except KeyboardInterrupt:
        print("\nвыход")

Запуск и проверка

export $(cat .env | xargs)
python main.py

Сценарий: Enter → «Расскажи в двух предложениях, почему небо голубое» → Enter → ждёшь ~3 сек → слышишь ответ.

У меня от Enter до начала озвучки получается 3.5–5 секунд: ~1.2 сек на Whisper + ~1.5 сек на Claude + ~0.5 сек на edge-tts + ~0.3 сек на старт проигрывания. Это терпимо, но не вау. Как разогнать — в «Подводных камнях».

Шаг 7. Tool use: реальные команды

Чтобы ассистент не только болтал, а ещё и делал что-то полезное, прикручиваем tool use. Минимальный пример — таймер и список покупок.

# в llm.py добавь:

TOOLS = [
    {
        "name": "set_timer",
        "description": "Поставить таймер на N секунд с подписью.",
        "input_schema": {
            "type": "object",
            "properties": {
                "seconds": {"type": "integer"},
                "label": {"type": "string"}
            },
            "required": ["seconds"]
        }
    },
    {
        "name": "add_to_shopping_list",
        "description": "Добавить пункт в список покупок.",
        "input_schema": {
            "type": "object",
            "properties": {"item": {"type": "string"}},
            "required": ["item"]
        }
    }
]


def execute_tool(name: str, args: dict) -> str:
    if name == "set_timer":
        sec = args["seconds"]
        label = args.get("label", "")
        # для простоты - просто пишем в файл, реальный таймер
        # делается через threading.Timer + системную нотификацию
        with open("timers.log", "a") as f:
            f.write(f"{sec}s | {label}\n")
        return f"Таймер на {sec} секунд поставлен."
    if name == "add_to_shopping_list":
        with open("shopping.txt", "a") as f:
            f.write(args["item"] + "\n")
        return f"Добавлено: {args['item']}"
    return f"Неизвестная команда {name}"


# и в Brain.reply замени вызов на:
resp = client.messages.create(
    model="claude-3-5-sonnet-latest",
    max_tokens=400,
    system=SYSTEM,
    tools=TOOLS,
    messages=msgs,
)

# обработка результата
if resp.stop_reason == "tool_use":
    tool_results = []
    for block in resp.content:
        if block.type == "tool_use":
            result = execute_tool(block.name, block.input)
            tool_results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": result
            })
    self.history.append({"role": "assistant", "content": resp.content})
    self.history.append({"role": "user", "content": tool_results})

    # второй вызов - чтобы получить финальную реплику для пользователя
    final = client.messages.create(
        model="claude-3-5-sonnet-latest",
        max_tokens=400, system=SYSTEM, tools=TOOLS,
        messages=self.history[-10:],
    )
    answer = final.content[0].text.strip()
else:
    answer = resp.content[0].text.strip()

Скажи «поставь таймер на пять минут на пасту» — увидишь, что Claude вызвал set_timer(300, "паста"), в timers.log появилась строка, а тебе озвучивается «Таймер на 300 секунд поставлен».

Расширения

  • Streaming TTS: начинать проигрывать ответ Claude не дожидаясь конца генерации. У Anthropic SDK есть стрим, у edge-tts тоже — можно резать ответ по предложениям и говорить по мере поступления. Сократит latency до 1.5 сек.
  • Wake word: чтобы не жать Enter, используй pvporcupine от Picovoice (бесплатно для личного, английский «Alexa» / «Hey Siri» есть из коробки). Свой wake word — за бабки.
  • VAD вместо Enter: webrtcvad или silero-vad определяет конец фразы по тишине 0.8 сек — пишешь автоматически.
  • История между сессиями: сохраняй brain.history в SQLite — ассистент будет помнить, о чём вы говорили вчера.
  • Подключение MCP: через Claude SDK ассистент может ходить в твой календарь, файлы, GitHub — см. урок c8.
  • Локально всё: вместо Claude — Ollama (см. p14). Тогда работает офлайн полностью.

Подводные камни

  • Latency на CPU. Модель small на старом ноуте (i5 2018) может транскрибировать 10 сек речи 4-5 сек. Бери tiny или ставь Ollama-backed Whisper на M-серии.
  • Whisper и русский. На tiny русский разваливается, путает падежи и имена. Минимум small, лучше medium. Названия брендов, имена коллег — почти всегда мимо, лечится словарём подсказок через initial_prompt.
  • Микрофон не пишет. macOS — выдай разрешение Terminal или твоему IDE в Privacy & Security → Microphone. Linux — проверь arecord -l, что устройство есть. Windows — иногда помогает выбрать конкретное устройство через sd.default.device = (input_id, output_id).
  • Edge-tts отваливается. Иногда возвращает пустой MP3 (rate limit / блокировка по региону). Обернул speak в try/except — на ошибке использую say на маке и espeak на linux как fallback.
  • Контекстное окно. Я держу последние 10 реплик. Если разговор затянулся — режь старое, иначе на длинных сессиях счёт за токены прыгает.
  • Шумоподавление. Если пишешь через AirPods — Whisper хорошо разбирает. Через встроенный микрофон ноута в кафе — становится плохо. Помогает noisereduce поверх записи или rnnoise.
