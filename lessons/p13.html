Проект «За 1 час»: Browser-расширение «AI рядом с текстом»

Что построим: Chrome-расширение — выделил текст → правый клик → объяснить Время: ~75 минут Уровень: базовый JavaScript + урок 6 курса

Что в итоге будет

Загружаешь в Chrome / Edge / Brave / Arc собственное расширение. На любой странице выделяешь кусок текста, кликаешь правой кнопкой — получаешь пункты «Объяснить», «Упростить», «Перевести». Через 1-2 секунды появляется попап с ответом Claude. Ничего никуда не вставлять, не переключать вкладки — AI прямо в контексте чтения.

Под капотом — Manifest V3 на чистом JS, без сборщиков, без React, без TypeScript. Минимум, который работает.

Архитектура

┌────────────────────┐
│ content.js         │ ← живёт на каждой вкладке,
│ - ловит выделение  │   рисует popup, шлёт сообщения
│ - рисует popup     │
└────────┬───────────┘
         │ chrome.runtime.sendMessage
         ↓
┌────────────────────┐
│ background.js      │ ← service worker, делает fetch к Anthropic,
│ - context menus    │   потому что content scripts CORS-ограничены
│ - вызов API        │
└────────┬───────────┘
         │ chrome.storage.local
         ↓
┌────────────────────┐
│ popup.html / .js   │ ← страница опций для ввода API-ключа
└────────────────────┘

Требования

  • Chrome / Edge / Brave / Arc (любой Chromium 110+).
  • Anthropic API-ключ.
  • Текстовый редактор и желание потыкаться в DevTools.

Шаг 1. Скелет расширения

mkdir ai-inline && cd ai-inline
touch manifest.json background.js content.js content.css popup.html popup.js

Шаг 2. manifest.json

Manifest V3 — текущий формат расширений. Главное отличие от V2: вместо background page — service worker, и более строгие разрешения.

{
  "manifest_version": 3,
  "name": "AI Inline",
  "version": "0.1.0",
  "description": "Объяснить, упростить, перевести выделенный текст через Claude",

  "permissions": [
    "contextMenus",
    "storage",
    "activeTab",
    "scripting"
  ],

  "host_permissions": [
    "https://api.anthropic.com/*"
  ],

  "background": {
    "service_worker": "background.js"
  },

  "content_scripts": [
    {
      "matches": ["<all_urls>"],
      "js": ["content.js"],
      "css": ["content.css"],
      "run_at": "document_idle"
    }
  ],

  "action": {
    "default_title": "AI Inline — настройки",
    "default_popup": "popup.html"
  }
}

host_permissions с явным api.anthropic.com — обязателен, иначе service worker не сможет туда сходить (Manifest V3 строгий с CORS).

Шаг 3. Хранение API-ключа

Никогда не хардкодь ключ в коде расширения. После загрузки в Chrome файлы лежат в plain text на диске, любой увидит. Используем chrome.storage.local + страницу настроек.

Файл popup.html:

             border-radius: 4px; cursor: pointer; }

Файл popup.js:

const keyInput = document.getElementById("key");
const statusEl = document.getElementById("status");

chrome.storage.local.get("apiKey", ({ apiKey }) => {
  if (apiKey) keyInput.value = apiKey;
});

document.getElementById("save").addEventListener("click", async () => {
  const apiKey = keyInput.value.trim();
  if (!apiKey.startsWith("sk-ant-")) {
    statusEl.textContent = "Похоже на не-Anthropic ключ.";
    return;
  }
  await chrome.storage.local.set({ apiKey });
  statusEl.textContent = "Сохранено.";
});

Шаг 4. Background worker — контекстное меню + вызов API

Контекстные меню регистрируем при установке. Сам вызов API делаем здесь же, потому что content script на arbitrary-сайте CORS-ограничен и не может ходить на anthropic.com.

Файл background.js:

const MENU_ITEMS = [
  { id: "explain",   title: "AI: объяснить",  prompt: explainPrompt },
  { id: "simplify",  title: "AI: упростить",  prompt: simplifyPrompt },
  { id: "translate", title: "AI: перевести",  prompt: translatePrompt },
];

function explainPrompt(text) {
  return `Объясни простыми словами следующий фрагмент.
Если есть жаргон или термины — раскрой.
Длина ответа 3-5 предложений.

Фрагмент:
"""
${text}
"""`;
}

function simplifyPrompt(text) {
  return `Перепиши фрагмент проще, короче, без воды.
Сохрани смысл, убери канцелярит.
Верни только переписанный текст, без комментариев.

Оригинал:
"""
${text}
"""`;
}

function translatePrompt(text) {
  return `Переведи фрагмент. Если оригинал на английском — переведи на русский.
Если на русском — переведи на английский. В остальных случаях
переведи на русский. Верни только перевод, без комментариев.

Фрагмент:
"""
${text}
"""`;
}

chrome.runtime.onInstalled.addListener(() => {
  for (const item of MENU_ITEMS) {
    chrome.contextMenus.create({
      id: item.id,
      title: item.title,
      contexts: ["selection"],
    });
  }
});

chrome.contextMenus.onClicked.addListener(async (info, tab) => {
  const item = MENU_ITEMS.find(m => m.id === info.menuItemId);
  if (!item || !info.selectionText) return;

  // 1. покажем "загрузка" на вкладке
  chrome.tabs.sendMessage(tab.id, {
    type: "show-loading",
    title: item.title
  });

  try {
    const answer = await callClaude(item.prompt(info.selectionText));
    chrome.tabs.sendMessage(tab.id, { type: "show-answer", text: answer });
  } catch (err) {
    chrome.tabs.sendMessage(tab.id, {
      type: "show-answer",
      text: `Ошибка: ${err.message}`
    });
  }
});

async function callClaude(prompt) {
  const { apiKey } = await chrome.storage.local.get("apiKey");
  if (!apiKey) {
    throw new Error("API key не задан. Нажми на иконку расширения.");
  }

  const resp = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: {
      "content-type": "application/json",
      "x-api-key": apiKey,
      "anthropic-version": "2023-06-01",
      // нужно для вызова из расширения, иначе 403
      "anthropic-dangerous-direct-browser-access": "true"
    },
    body: JSON.stringify({
      model: "claude-3-5-haiku-latest",   // быстро и дёшево для inline
      max_tokens: 600,
      messages: [{ role: "user", content: prompt }]
    })
  });

  if (!resp.ok) {
    const body = await resp.text();
    throw new Error(`${resp.status}: ${body.slice(0, 200)}`);
  }

  const data = await resp.json();
  return data.content[0].text;
}

Обрати внимание на хедер anthropic-dangerous-direct-browser-access. Без него Anthropic API отвечает 403 при прямом вызове из браузера. Они защищаются от того, что ты случайно встроишь ключ в публичный сайт. Для расширения, где ключ хранится в локальном storage пользователя — окей.

Шаг 5. Content script — попап на странице

Content script вставляется в каждую вкладку. Его задача — нарисовать модальное окно с ответом. Никаких iframe'ов, чтобы не ломать вёрстку чужих сайтов — просто div поверх с высоким z-index.

Файл content.css:

Файл content.js:

const POPUP_ID = "ai-inline-popup";

function ensurePopup(title) {
  let el = document.getElementById(POPUP_ID);
  if (el) el.remove();

  el = document.createElement("div");
  el.id = POPUP_ID;
  el.innerHTML = `
    <header>
      <h4>${title}</h4>
      <button class="close" aria-label="Закрыть">×</button>
    </header>
    <div class="body"></div>
  `;
  el.querySelector("button.close").addEventListener("click", () => el.remove());
  document.body.appendChild(el);

  // закрытие по Esc
  const onKey = (e) => {
    if (e.key === "Escape") { el.remove(); document.removeEventListener("keydown", onKey); }
  };
  document.addEventListener("keydown", onKey);

  return el;
}

chrome.runtime.onMessage.addListener((msg) => {
  if (msg.type === "show-loading") {
    const el = ensurePopup(msg.title);
    el.querySelector(".body").innerHTML =
      '<div class="loading">Думаю...</div>';
  }
  if (msg.type === "show-answer") {
    const el = document.getElementById(POPUP_ID) || ensurePopup("Ответ");
    el.querySelector(".body").textContent = msg.text;
  }
});

z-index: 2147483647 — это Int32.MAX. Гарантирует, что попап будет поверх любого сайта (часто видел кастомные модалки с z-index 9999999).

Шаг 6. Загрузка в Chrome

  1. Открой chrome://extensions/.
  2. Включи «Developer mode» (правый верхний).
  3. «Load unpacked» → выбери папку ai-inline.
  4. Расширение появится в списке. Кликни на иконку в тулбаре — откроется popup для ввода ключа. Введи и сохрани.

Запуск и проверка

  1. Открой любую статью (Habr, Wikipedia, NYTimes).
  2. Выдели абзац.
  3. Правый клик → должен появиться раздел с «AI: объяснить / упростить / перевести».
  4. Клик → справа сверху появится попап «Думаю…», через 1-2 секунды — ответ.

Если попап не появляется — открой DevTools на странице (Cmd+Opt+I), там увидишь ошибки content script. Service worker отлаживается отдельно: chrome://extensions/ → твоё расширение → «service worker» → откроется отдельный DevTools.

Шаг 7. Добавляем «Резюмировать страницу»

Полезное расширение — действие без выделения, на всю страницу.

В background.js добавь пункт меню с другим контекстом:

chrome.runtime.onInstalled.addListener(() => {
  // ... прежние пункты ...
  chrome.contextMenus.create({
    id: "summarize-page",
    title: "AI: резюме страницы",
    contexts: ["page"],
  });
});

chrome.contextMenus.onClicked.addListener(async (info, tab) => {
  if (info.menuItemId === "summarize-page") {
    chrome.tabs.sendMessage(tab.id, { type: "show-loading", title: "Резюме" });

    // вытащить основной текст со страницы
    const [{ result: pageText }] = await chrome.scripting.executeScript({
      target: { tabId: tab.id },
      func: () => document.body.innerText.slice(0, 20000),
    });

    try {
      const answer = await callClaude(
        `Сделай резюме страницы в 5-7 пунктах. Текст:\n\n${pageText}`
      );
      chrome.tabs.sendMessage(tab.id, { type: "show-answer", text: answer });
    } catch (err) {
      chrome.tabs.sendMessage(tab.id, {
        type: "show-answer", text: `Ошибка: ${err.message}`
      });
    }
    return;
  }
  // ... остальная логика для selection ...
});

После правки background.js нажми «Reload» на карточке расширения в chrome://extensions/ — service worker перезапустится с новой логикой.

Расширения

  • «Объяснить как 10-летнему» / «Объяснить как PhD»: два отдельных пункта меню с разными промптами. По одной фразе подбираешь нужный уровень.
  • Стриминг ответа: Anthropic API поддерживает SSE, текст можно показывать по мере поступления — попап перестаёт «зависать на 2 секунды».
  • История запросов: сохраняй в chrome.storage.local последние 50 запросов с ответами. Отдельная страница options.html, чтобы посмотреть.
  • Свои промпты: страница опций, где пользователь добавляет кастомные пункты меню («перевести как маркетолог», «упростить для бабушки»).
  • «Найти источники»: промпт «дай 3 ключевых утверждения из текста и предположи, какие источники их подтвердят/опровергнут». Дальше можно подключить web search через MCP.
  • Локальная модель: вместо Anthropic — Ollama на localhost:11434 (см. p14). Получается полностью офлайн расширение.

Подводные камни

  • 403 от Anthropic. Забыт хедер anthropic-dangerous-direct-browser-access или ключ просрочен.
  • Контекстное меню не появляется. Проверь, что в manifest есть "contextMenus" в permissions и в коде contexts: ["selection"].
  • Попап ломается на странице. Сайты с агрессивным CSS могут перебить стили — добавь !important к ключевым правилам или вынеси попап в Shadow DOM.
  • Service worker «засыпает». В MV3 он останавливается через ~30 сек простоя. Не держи там состояние — всё хранение через chrome.storage.
  • CSP сайтов. Content Security Policy у некоторых сайтов блокирует inline-стили. Поэтому отдельный content.css, а не style="".
  • Ключ виден на диске. Chrome шифрует chrome.storage, но root-доступ к машине = доступ к ключу. Не давай расширение коллегам с своим ключом.
  • Анивирусы. «Чужое» неподписанное расширение иногда вызывает у IT-отдела вопросы. Для команды лучше публиковать через Chrome Web Store (одноразово $5, потом релизы бесплатно).

Что в итоге

В руках:

  1. Полноценное Manifest V3 расширение на ~250 строк, без сборки и фреймворков.
  2. Безопасное хранение API-ключа через chrome.storage.
  3. Понимание разделения content script / service worker / popup — оно одинаковое во всех Chromium-расширениях.
  4. Фундамент, на котором делается всё: от грамматических корректоров до встроенных переводчиков и AI-собеседников.
Идея: сделай расширение под свою конкретную работу. Чтец длинных PDF? Кнопка «выжимка раздела». Покупаешь криптовалюту? «Объяснить смарт-контракт». Готовишься к экзамену? «Сделай флэш-карточки из выделенного». Расширения — это идеальный формат для гипер-нишевых инструментов «для себя одного».
