Проект: ИИ-ресёрчер конкурентов с дайджестом на почту

Что построим: скрипт, который раз в день проверяет блоги, сообщества ВКонтакте и страницы сайтов конкурентов и присылает на почту короткий дайджест: что нового и что это значит для тебя Время: ~2 часа работы. Пароль приложения для почты начинает действовать через 2–3 часа, поэтому создай его первым Уровень: уверенный: Python 3.10+, терминал, переменные окружения Стек: Python, YandexGPT (Yandex AI Studio), VK API, Яндекс Почта. Всё работает из России без VPN и оплачивается российской картой

Зачем

«Что нового у конкурентов?» Ответ нужен каждую неделю, а искать его скучно. Скрипт делает это сам: читает их блоги, посты в сообществах ВКонтакте и страницы сайта без RSS (цены, каталог, акции), находит новое и присылает тебе письмо из 3–5 пунктов по каждому конкуренту.

Как это устроено

Расписание (раз в сутки) →
  для каждого конкурента:
    RSS блога / стена сообщества VK / страница сайта →
    что появилось с прошлой проверки (state.json) →
    YandexGPT: 3–5 пунктов «что нового и что это значит» →
  одно письмо на почту (Telegram по желанию)
Почему такой стек. API Anthropic в России недоступен и российской картой не оплачивается. Telegram с февраля 2026 года в России работает с перебоями, у многих только через VPN, а api.telegram.org с российских адресов может не открываться. Поэтому модель здесь YandexGPT, а дайджест приходит письмом. Telegram оставили как опцию.

Шаг 0. Пароль приложения для почты (5 мин, сделай первым)

Скрипт отправляет письмо через SMTP Яндекс Почты. Обычный пароль от Яндекс ID для этого не подходит, нужен пароль приложения.

  1. Открой id.yandex.ru/security → «Доступ к вашим данным» → «Пароли приложений».
  2. Выбери тип «Почта», задай имя, например digest, нажми «Далее». Пароль покажут один раз: сразу скопируй.
  3. В настройках Почты открой раздел «Почтовые программы». Включи «С сервера imap.yandex.ru по протоколу IMAP» и проверь, что включено «Пароли приложений и OAuth-токены». Сохрани.

Пароль начнёт действовать через 2–3 часа. Пока ждёшь, делай остальные шаги.

Шаг 1. Ключ YandexGPT (15 мин)

  1. Зайди в Yandex AI Studio через Яндекс ID и создай организацию. Каталог default появится сам.
  2. Привяжи платёжный аккаунт. Физлицо привязывает карту; резиденты России платят в рублях картами российских банков (Мир, Visa, MasterCard).
  3. Нажми «Создать API-ключ» в правом верхнем углу. Сервисный аккаунт с нужными правами создастся вместе с ключом. Сохрани секрет ключа: он понадобится в шаге 4.
  4. Скопируй идентификатор каталога (folder_id): наведи курсор на имя каталога, он скопируется в буфер.

Модель по умолчанию в скрипте: YandexGPT Pro 5.1 (yandexgpt-5.1), 0,8 ₽ за 1000 токенов на входе и столько же на выходе. YandexGPT Lite (yandexgpt-5-lite) в четыре раза дешевле, 0,2 ₽, но пишет проще. Запуск, в котором новое нашлось у 5–10 конкурентов, это примерно 5–20 тысяч токенов, то есть 4–16 ₽ на Pro 5.1. Если нового нет, модель не вызывается и денег не тратит.

Шаг 2. Сервисный ключ ВКонтакте (10 мин, если следишь за сообществами)

Посты сообществ читаем методом wall.get VK API. Ему хватает сервисного ключа приложения: вход пользователя не нужен.

  1. Создай приложение в кабинете VK ID. При создании VK ID выдаёт сервисный ключ доступа, он лежит в настройках приложения.
  2. Срок действия у ключа не ограничен. Храни его только у себя на компьютере или сервере. Если ключ утёк, обнови его в настройках приложения.

Так читаются только открытые сообщества. Закрытые группы скрипт не увидит, и это правильно.

Шаг 3. Зависимости

pip install openai httpx feedparser beautifulsoup4

Пакет openai нужен не ради OpenAI: у Yandex AI Studio есть OpenAI-совместимый API, и этот клиент с ним работает. Нужен Python 3.10 или новее.

Шаг 4. Ключи в переменных окружения

Ключи не пишем в код. Создай рядом со скриптом файл secrets.sh:

export YC_API_KEY="секрет API-ключа AI Studio"
export YC_FOLDER_ID="идентификатор каталога"
export VK_SERVICE_KEY="сервисный ключ VK"     # если следишь за VK
export SMTP_USER="you@yandex.ru"
export SMTP_PASSWORD="пароль приложения из шага 0"
export MAIL_TO="you@yandex.ru"                 # можно несколько через запятую
# export YC_MODEL="yandexgpt-5-lite"           # если нужна модель дешевле

Закрой файл от чужих глаз: chmod 600 secrets.sh. Если код лежит в git, допиши secrets.sh в .gitignore.

Шаг 5. Источники (20 мин)

Весь код дальше собирай в один файл main.py, блок за блоком, сверху вниз. Первый блок: список конкурентов.

SOURCES = [
    {"name": "Конкурент А", "type": "rss", "url": "https://example.com/blog/feed"},
    {"name": "Конкурент Б", "type": "vk", "domain": "example_shop"},
    {"name": "Конкурент В", "type": "page", "url": "https://example.org/prices",
     "selector": "main"},
]

Три типа источников:

  • rss: лента блога или новостей. Попробуй адреса /feed, /rss, /blog/feed или найди в коде страницы ссылку с application/rss+xml.
  • vk: открытое сообщество ВКонтакте. В domain пиши короткий адрес, то есть часть ссылки после vk.com/.
  • page: страница сайта без RSS, например цены или каталог. В selector укажи CSS-селектор блока с содержимым (посмотри через «Просмотреть код» в браузере), чтобы меню и баннеры не считались изменениями. Без селектора скрипт берёт всю страницу.
Только открытые источники. Скрипт читает то, что видит любой посетитель, раз в сутки, и перед чтением страницы проверяет robots.txt. Карточки на маркетплейсах им не собирай: у площадок свои правила доступа к данным. Разбор карточек конкурентов удобнее сделать вручную с чат-ИИ.

Шаг 6. Память: что уже видели

Скрипт помнит, какие записи уже разобрал, и хранит последний снимок каждой страницы. Всё лежит в state.json. В памяти номера записей держим во множестве (set): проверка «уже видели?» быстрая и без повторов. JSON множества не умеет, поэтому на диск пишем список.

import json, os

STATE_FILE = "state.json"

def load_state():
    if not os.path.exists(STATE_FILE):
        return {"seen": {}, "pages": {}}
    with open(STATE_FILE, encoding="utf-8") as f:
        data = json.load(f)
    # на диске списки, в памяти множества: проверка "уже видели?" быстрая
    data["seen"] = {name: set(ids) for name, ids in data["seen"].items()}
    return data

def save_state(state):
    data = {"seen": {name: sorted(ids) for name, ids in state["seen"].items()},
            "pages": state["pages"]}
    with open(STATE_FILE, "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=1)

Шаг 7. Блоги: RSS

Все источники приводим к одному виду: id, title, text, link. Тогда остальной код не думает, откуда пришла запись.

import httpx, feedparser
from bs4 import BeautifulSoup

USER_AGENT = "competitor-digest/1.0"

def clean(html):
    return BeautifulSoup(html or "", "html.parser").get_text(" ", strip=True)

def fetch_rss(src, state):
    r = httpx.get(src["url"], headers={"User-Agent": USER_AGENT},
                  timeout=30, follow_redirects=True)
    r.raise_for_status()
    feed = feedparser.parse(r.content)
    items = []
    for e in feed.entries:
        items.append({
            "id": e.get("id") or e.get("link") or e.get("title", ""),
            "title": e.get("title", ""),
            "text": clean(e.get("summary", "")),
            "link": e.get("link", ""),
        })
    return items

Шаг 8. Сообщества ВКонтакте

Запрос идёт на api.vk.ru, ключ передаём в заголовке Authorization: Bearer, версию API в параметре v. Берём 20 последних постов, метод отдаёт до 100.

VK_API = "https://api.vk.ru/method/wall.get"
VK_VERSION = "5.199"

def fetch_vk(src, state):
    r = httpx.get(VK_API,
                  params={"domain": src["domain"], "count": 20, "v": VK_VERSION},
                  headers={"Authorization": f"Bearer {os.environ['VK_SERVICE_KEY']}"},
                  timeout=30)
    data = r.json()
    if "error" in data:
        raise RuntimeError(data["error"].get("error_msg", "ошибка VK API"))
    items = []
    for post in data["response"]["items"]:
        items.append({
            "id": str(post["id"]),
            "title": "",
            "text": post.get("text", ""),
            "link": f"https://vk.com/wall{post['owner_id']}_{post['id']}",
        })
    return items

Шаг 9. Страницы без RSS

Скачиваем страницу, оставляем текст нужного блока и сравниваем с прошлым снимком. В дайджест уходят только изменившиеся строки: + добавилось, - пропало. В первый раз скрипт просто запоминает страницу.

import difflib, hashlib
from urllib.parse import urlsplit
from urllib.robotparser import RobotFileParser

def allowed_by_robots(url):
    parts = urlsplit(url)
    rp = RobotFileParser(f"{parts.scheme}://{parts.netloc}/robots.txt")
    rp.read()
    return rp.can_fetch(USER_AGENT, url)

def fetch_page(src, state):
    url = src["url"]
    if not allowed_by_robots(url):
        raise RuntimeError("robots.txt запрещает читать эту страницу")
    r = httpx.get(url, headers={"User-Agent": USER_AGENT},
                  timeout=30, follow_redirects=True)
    r.raise_for_status()
    soup = BeautifulSoup(r.text, "html.parser")
    for tag in soup(["script", "style", "noscript"]):
        tag.decompose()
    part = soup.select_one(src["selector"]) if src.get("selector") else soup
    if part is None:
        raise RuntimeError(f"на странице нет блока {src['selector']}")
    lines = [s.strip() for s in part.get_text("\n").splitlines() if s.strip()]
    text = "\n".join(lines)

    old = state["pages"].get(src["name"])
    state["pages"][src["name"]] = text
    if old is None or old == text:
        return []  # первый снимок или ничего не поменялось
    diff = [d for d in difflib.ndiff(old.splitlines(), lines)
            if d.startswith(("+ ", "- "))]
    diff_text = "\n".join(diff[:60])
    return [{
        "id": hashlib.sha256(diff_text.encode("utf-8")).hexdigest()[:16],
        "title": "Изменения на странице",
        "text": diff_text,
        "link": url,
    }]

Шаг 10. Дайджест через YandexGPT

Клиент OpenAI смотрит на Yandex AI Studio: адрес https://ai.api.cloud.yandex.net/v1, ключ AI Studio, folder_id в параметре project. Модель задаётся как gpt://<folder_id>/yandexgpt-5.1.

from openai import OpenAI

FOLDER_ID = os.environ["YC_FOLDER_ID"]
MODEL = os.environ.get("YC_MODEL", "yandexgpt-5.1")

llm = OpenAI(api_key=os.environ["YC_API_KEY"], project=FOLDER_ID,
             base_url="https://ai.api.cloud.yandex.net/v1")

PROMPT = """Конкурент: {name}
Что у него появилось с прошлой проверки (посты, статьи, изменения на сайте;
строки с "+" добавились, с "-" пропали):

{text}

Сделай дайджест из 3-5 пунктов:
- что нового: товар, цена, акция, ассортимент, партнёрство, найм;
- что это значит для нас;
- пометка: угроза, нейтрально или возможность.
Опирайся только на текст выше, не додумывай. Если важного нет,
напиши одной строкой: «Ничего важного». Пиши простым текстом, без разметки."""

def summarize(items, name):
    text = "\n\n".join(f"{it['title']}\n{it['text'][:1500]}\n{it['link']}"
                       for it in items)
    resp = llm.chat.completions.create(
        model=f"gpt://{FOLDER_ID}/{MODEL}",
        messages=[{"role": "user", "content": PROMPT.format(name=name, text=text)}],
        temperature=0.3,
        max_tokens=800,
    )
    return resp.choices[0].message.content.strip()

Если у тебя есть доступ к API Anthropic (Россия не входит в список стран, где он доступен), можно взять Claude. Поставь pip install anthropic, положи ключ в ANTHROPIC_API_KEY, создай client = anthropic.Anthropic() и в summarize замени вызов на client.messages.create(model="claude-sonnet-5-5", max_tokens=800, messages=[...]). Текст ответа лежит в msg.content[0].text.

GigaChat API от Сбера тоже работает из России, но настраивать его дольше: по ключу авторизации нужно получать токен доступа, он живёт 30 минут. С 1 сентября 2026 года новые клиенты оплачивают его на платформе cloud.ru. С клиентом OpenAI он совместим частично.

Шаг 11. Письмо на почту

Яндекс Почта принимает письма от программ на smtp.yandex.ru, порт 465, SSL. Логин: твой адрес, пароль: пароль приложения из шага 0.

import smtplib
from email.message import EmailMessage

def send_email(subject, body):
    msg = EmailMessage()
    msg["Subject"] = subject
    msg["From"] = os.environ["SMTP_USER"]
    msg["To"] = os.environ["MAIL_TO"]
    msg.set_content(body)
    with smtplib.SMTP_SSL("smtp.yandex.ru", 465, timeout=30) as smtp:
        smtp.login(os.environ["SMTP_USER"], os.environ["SMTP_PASSWORD"])
        smtp.send_message(msg)

По желанию: копия в Telegram

Если Telegram работает и у тебя, и у тех, кто читает дайджест, добавь функцию ниже и две переменные: TG_BOT_TOKEN (бот создаётся у @BotFather) и TG_CHAT_ID. Telegram принимает до 4096 знаков в сообщении, поэтому длинный дайджест режем на части. Разметку не включаем: звёздочки и подчёркивания из ответа модели ломают Markdown.

def send_telegram(text):
    token = os.environ["TG_BOT_TOKEN"]
    for i in range(0, len(text), 4000):  # лимит Telegram 4096 знаков
        r = httpx.post(f"https://api.telegram.org/bot{token}/sendMessage",
                       json={"chat_id": os.environ["TG_CHAT_ID"],
                             "text": text[i:i + 4000]},
                       timeout=30)
        r.raise_for_status()

Если Telegram не нужен, этот блок можно не добавлять: скрипт вызывает его, только когда задана переменная TG_BOT_TOKEN.

Шаг 12. Основной цикл

from datetime import date

FETCHERS = {"rss": fetch_rss, "vk": fetch_vk, "page": fetch_page}
MAX_ITEMS = 10      # не больше 10 новых записей на конкурента за раз
FIRST_RUN_ITEMS = 3 # в первый раз разбираем только 3 последние записи

def main():
    state = load_state()
    pages_before = dict(state["pages"])
    parts, errors = [], []
    for src in SOURCES:
        name = src["name"]
        try:
            items = FETCHERS[src["type"]](src, state)
            first_run = name not in state["seen"]
            known = state["seen"].setdefault(name, set())
            new = [it for it in items if it["id"] not in known]
            if new:
                limit = FIRST_RUN_ITEMS if first_run else MAX_ITEMS
                parts.append(f"{name}\n{summarize(new[:limit], name)}")
            known.update(it["id"] for it in new)
        except Exception as e:
            errors.append(f"{name}: {e}")
            # снимок страницы не обновляем, чтобы не потерять изменения
            if name in pages_before:
                state["pages"][name] = pages_before[name]
            else:
                state["pages"].pop(name, None)

    if not parts and not errors:
        print("Нового нет, письмо не отправляю")
        save_state(state)
        return
    body = "\n\n".join(parts) or "Нового нет."
    if errors:
        body += "\n\nНе удалось проверить:\n" + "\n".join(errors)
    subject = f"Конкуренты: что нового, {date.today():%d.%m.%Y}"
    send_email(subject, body)
    if os.environ.get("TG_BOT_TOKEN"):
        try:
            send_telegram(f"{subject}\n\n{body}")
        except Exception as e:
            print("Telegram не ответил:", e)
    save_state(state)  # сохраняем, только если письмо ушло

if __name__ == "__main__":
    main()

Что здесь важно:

  • В первый раз по каждому источнику разбираются только 3 последние записи, остальные просто запоминаются. Иначе первое письмо будет огромным.
  • Если источник упал (сайт не открылся, ключ VK неверный), остальные всё равно проверяются, а ошибка попадает в конец письма.
  • state.json сохраняется только после того, как письмо ушло. Не ушло: в следующий раз то же новое придёт снова, ничего не потеряется.

Шаг 13. Первый запуск (10 мин)

. ./secrets.sh
python3 main.py

Проверь письмо: у каждого пункта должна быть реальная запись или изменение на странице за ним. Запусти ещё раз: должно появиться «Нового нет, письмо не отправляю». Если первое письмо не пришло, а ошибка про логин, проверь, прошли ли 2–3 часа с создания пароля приложения.

Шаг 14. Расписание (15 мин)

Свой компьютер или сервер. Самый простой путь: cron. Открой crontab -e и добавь строку (запуск каждый день в 9:00):

0 9 * * * cd /path/to/project && . ./secrets.sh && /usr/bin/python3 main.py >> digest.log 2>&1

Путь к Python узнай командой which python3 и подставь свой. Компьютер в это время должен быть включён, поэтому надёжнее небольшой сервер. На Windows то же самое делает Планировщик заданий.

GitHub Actions, если GitHub у тебя открывается. Создай приватный репозиторий с main.py, ключи добавь в Settings → Secrets and variables → Actions, а этот файл положи в .github/workflows/digest.yml:

name: digest
on:
  schedule:
    - cron: "0 9 * * *"
      timezone: "Europe/Moscow"
  workflow_dispatch:
permissions:
  contents: write
jobs:
  run:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-python@v7
        with:
          python-version: "3.12"
      - run: pip install openai httpx feedparser beautifulsoup4
      - run: python main.py
        env:
          YC_API_KEY: ${{ secrets.YC_API_KEY }}
          YC_FOLDER_ID: ${{ secrets.YC_FOLDER_ID }}
          VK_SERVICE_KEY: ${{ secrets.VK_SERVICE_KEY }}
          SMTP_USER: ${{ secrets.SMTP_USER }}
          SMTP_PASSWORD: ${{ secrets.SMTP_PASSWORD }}
          MAIL_TO: ${{ secrets.MAIL_TO }}
      - run: |
          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git add state.json
          git commit -m "update state" || echo "nothing to commit"
          git push

Последний шаг сохраняет state.json обратно в репозиторий, иначе каждый запуск начинался бы с нуля. Оговорки:

  • Серверы GitHub стоят за рубежом. Запросы к YandexGPT, VK и smtp.yandex.ru пойдут оттуда. Проверь вручную кнопкой Run workflow (её даёт workflow_dispatch), прежде чем полагаться на расписание.
  • Запуск по расписанию может опаздывать, когда GitHub загружен. Для приватных репозиториев на бесплатном тарифе есть 2000 минут в месяц, ежедневному скрипту хватит с запасом.
  • В публичном репозитории расписание само отключается, если 60 дней в нём не было активности.

Если не работает

  • Ошибка входа в SMTP: пароль приложения ещё не заработал (2–3 часа), не включён доступ для почтовых программ или вместо пароля приложения стоит обычный.
  • VK отвечает ошибкой: проверь ключ и короткий адрес сообщества. Закрытые сообщества сервисный ключ не читает.
  • «robots.txt запрещает»: сайт просит роботов эту страницу не читать. Убери её из списка или найди у конкурента RSS.
  • Страница «меняется» каждый день: в блок попадают дата, счётчики или случайные товары. Сузь selector до нужной части.
  • Модель отвечает 400: проверь имя модели. Устаревшие модели Yandex отключает, и старый адрес перестаёт работать. Актуальный список в документации AI Studio.

Расширения

  • Вакансии конкурентов: страница «Карьера» как источник типа page. Кого нанимают, туда и растут.
  • Недельный отчёт: раз в неделю отдай модели все письма за 7 дней и попроси тренды.
  • Несколько читателей: перечисли адреса в MAIL_TO через запятую.
