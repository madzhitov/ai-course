Проект «За 1 час»: AI-ресёрчер конкурентов с TG-дайджестом

Что построим: скрипт, ежедневно сканирующий конкурентов и присылающий дайджест в Telegram Время: ~75 минут Уровень: Python + urok 14 (RAG)

Зачем

«Что нового у конкурентов?» — занудный вопрос, на который нужно знать ответ еженедельно. Скрипт автоматизирует: парсит их сайты/блоги/changelog, выделяет изменения, отправляет краткий дайджест в твой Telegram.

Архитектура

Cron (раз в сутки) →
  for each competitor:
    fetch sitemap/RSS →
    diff vs yesterday →
    Claude summarize new content →
  collate → format → Telegram bot

Шаг 1. Зависимости

pip install anthropic httpx feedparser python-telegram-bot beautifulsoup4

Шаг 2. Источники

SOURCES = [
  {"name": "Competitor A", "rss": "https://compA.com/feed.xml"},
  {"name": "Competitor B", "rss": "https://compB.com/blog/rss"},
  {"name": "Competitor C", "changelog": "https://compC.com/changelog"},
]

Шаг 3. Парсинг RSS + дифф

import feedparser, json, os
SEEN_FILE = "seen.json"
seen = json.load(open(SEEN_FILE)) if os.path.exists(SEEN_FILE) else {}

def fetch_new(source):
    feed = feedparser.parse(source["rss"])
    new = [e for e in feed.entries if e.id not in seen.get(source["name"], set())]
    seen.setdefault(source["name"], []).extend(e.id for e in new)
    return new

Шаг 4. Суммаризация через Claude

import anthropic
client = anthropic.Anthropic()

def summarize(entries, competitor):
    text = "\n\n".join(f"## {e.title}\n{e.summary}" for e in entries)
    msg = client.messages.create(
      model="claude-sonnet-4-5",
      max_tokens=600,
      messages=[{"role": "user", "content": f'''Конкурент: {competitor}
Новые публикации:
{text}

Сделай дайджест (3–5 буллетов):
- Что нового (продукт / фича / партнёрство / маркетинговый ход)?
- Что это значит для нас?
- Опасно / нейтрально / возможность.

Только важное. Прямо, без воды.'''}]
    )
    return msg.content[0].text

Шаг 5. Telegram

import httpx
BOT_TOKEN = os.environ["TG_BOT_TOKEN"]
CHAT_ID = os.environ["TG_CHAT_ID"]

def send_telegram(text):
    httpx.post(f"https://api.telegram.org/bot{BOT_TOKEN}/sendMessage",
               json={"chat_id": CHAT_ID, "text": text, "parse_mode": "Markdown"})

Шаг 6. Основной цикл

def main():
    digest = "🔍 *Конкуренты — что нового:*\n\n"
    for src in SOURCES:
        new = fetch_new(src)
        if not new: continue
        digest += f"*{src['name']}*:\n{summarize(new, src['name'])}\n\n"
    send_telegram(digest)
    json.dump(seen, open(SEEN_FILE, "w"))
