Проект «За 1 час»: Личный AI-секретарь — автоответы на email + дневной чек-ин

Что построим: скрипт, который утром читает inbox, классифицирует письма, готовит черновики типовых ответов и присылает дневной чек-ин в Telegram Время: ~90 минут Уровень: Python средний, базовое понимание IMAP

Зачем этот проект

У меня в почте каждое утро 30–80 писем: часть — реально важные, часть — FYI-рассылки, часть — типовые («подтвердите слот», «пришлите счёт», «можете созвониться в среду?»). Я тратил по 40 минут на разбор, ещё не приступив к работе.

Этот скрипт делает за меня первый проход: помечает срочное, готовит черновики на типовые письма (я их потом просто проверяю и отправляю одной кнопкой), а в Telegram присылает короткий бриф «у тебя сегодня 3 срочных, 2 встречи на согласование, остальное — мусор». Я начинаю день не с inbox-paralysis, а с понимания картины.

Что в итоге будет

  • Python-скрипт, запускающийся по cron каждое утро в 8:00.
  • Чтение inbox через IMAP, безопасно (app-password, не основной пароль).
  • Классификация писем через Claude: срочное / FYI / шум / типовое.
  • На «типовое» — готовый draft ответа сохраняется в папке «Черновики» твоего почтового ящика.
  • Сообщение в Telegram: «📬 Утренний бриф: 4 срочных, 7 FYI, 12 шум. Подготовил 3 черновика».

Требования

  • Python 3.10+.
  • Почтовый ящик с включённым IMAP (Gmail, Yandex, FastMail, ProtonBridge — что угодно).
  • App-password, а не основной пароль аккаунта (см. ниже).
  • API-ключ Anthropic (Claude).
  • Telegram-бот (через @BotFather) и свой chat_id.

Архитектура

cron (8:00 утра)
    ↓
fetch_inbox.py
    ├─→ IMAP: достать письма за последние 24 часа (тема + первые 1500 символов тела)
    ├─→ Claude: классифицировать каждое (urgent / fyi / noise / template)
    ├─→ для template: сгенерить draft ответа → положить в IMAP Drafts
    └─→ Telegram: отправить дневной чек-ин

Шаг 1: app-password и переменные окружения

Никогда не вбивай основной пароль от почты в скрипт. Все нормальные провайдеры дают «application-specific password» — отдельный пароль для скриптов, который можно отозвать в любой момент.

Gmail: myaccount.google.com → Безопасность → 2-Step Verification → App passwords → создать. Получишь 16-символьную строку.

Yandex: id.yandex.ru → Безопасность → Пароли приложений → «Почта». Дальше IMAP-настройки.

Создай проект:

mkdir ai-secretary && cd ai-secretary
python3 -m venv venv && source venv/bin/activate
pip install imap-tools anthropic python-telegram-bot python-dotenv

Шаг 2: достаём свежие письма

Библиотека imap-tools сильно приятнее стандартного imaplib — нормальный API без боли с байтами.

Файл fetch_inbox.py:

import os
from datetime import datetime, timedelta
from dotenv import load_dotenv
from imap_tools import MailBox, AND

load_dotenv()

def fetch_recent_emails(hours=24):
    """Достаём письма за последние N часов из INBOX."""
    since = (datetime.now() - timedelta(hours=hours)).date()
    emails = []

    with MailBox(os.getenv("IMAP_HOST")).login(
        os.getenv("IMAP_USER"),
        os.getenv("IMAP_PASS"),
        initial_folder="INBOX"
    ) as mailbox:
        for msg in mailbox.fetch(AND(date_gte=since), mark_seen=False):
            emails.append({
                "uid": msg.uid,
                "from": msg.from_,
                "subject": msg.subject or "(без темы)",
                "date": msg.date.isoformat() if msg.date else "",
                # обрезаем тело, чтобы не сжечь токены на длинных рассылках
                "body": (msg.text or msg.html or "")[:1500],
            })
    return emails


if __name__ == "__main__":
    mails = fetch_recent_emails(24)
    print(f"Получено {len(mails)} писем за 24 часа")
    for m in mails[:3]:
        print(f"  {m['from']} | {m['subject']}")

Запусти — должно вывести количество и первые 3 темы. Если падает на логине — проверь, что IMAP включён и используешь app-password.

Шаг 3: классифицируем через Claude

Главный трюк: классифицируем не по одному, а пачкой в одном запросе. Дешевле и быстрее.

Файл classify.py:

import json
import os
from anthropic import Anthropic

client = Anthropic(api_key=os.getenv("ANTHROPIC_API_KEY"))

CLASSIFY_PROMPT = """Ты — личный секретарь. Классифицируй каждое письмо в одну из категорий:

- "urgent" — требует ответа сегодня. Прямой вопрос лично мне, дедлайн, проблема в проде, срочная просьба от руководства/клиента.
- "fyi" — нужно прочитать, но не отвечать. Уведомления о решениях, рассылки из подписок, которые я реально читаю, отчёты.
- "noise" — можно не открывать. Маркетинг, спам, авто-уведомления систем (PR-апдейты, билд-уведомления, дайджесты).
- "template" — типовой запрос, на который есть стандартный ответ. Подтверждение слота встречи, запрос счёта/документов, «можете созвониться в среду в 15:00?», «пришлите КП».

Для "template" дополнительно поле "draft" — текст черновика ответа на русском, в моём стиле:
короткий, без воды, без формальностей вроде «Добрый день, уважаемый...». Просто по делу.

Верни строго JSON-массив, по одному объекту на письмо, в том же порядке:
[
  {"uid": "123", "category": "urgent", "reason": "клиент спрашивает про дедлайн"},
  {"uid": "124", "category": "template", "reason": "запрос слота",
   "draft": "Привет! Среда 15:00 подходит. Скину ссылку на звонок утром."},
  ...
]
Никакого markdown, только JSON."""


def classify_batch(emails):
    """Классифицируем пачку писем за один вызов."""
    if not emails:
        return []

    # формируем компактное описание для модели
    payload = [
        {
            "uid": e["uid"],
            "from": e["from"],
            "subject": e["subject"],
            "body_preview": e["body"][:800],
        }
        for e in emails
    ]

    resp = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=4000,
        system=CLASSIFY_PROMPT,
        messages=[{"role": "user", "content": json.dumps(payload, ensure_ascii=False)}],
    )

    text = resp.content[0].text.strip()
    # на всякий случай отрезаем возможные обёртки
    if text.startswith("```"):
        text = text.split("```")[1]
        if text.startswith("json"):
            text = text[4:]
    return json.loads(text)

Я выбрал claude-sonnet-4-5 — она достаточно умная для нюансов («это срочно от босса» vs «это рассылка от Jira»). Haiku тоже подойдёт, но иногда промахивается с «template».

Шаг 4: сохраняем черновики в папку Drafts

Это самая магическая часть. Скрипт кладёт сгенерированный черновик прямо в почтовый клиент — открываешь утром почту, видишь готовые драфты, проверяешь, кликаешь «Отправить».

from email.message import EmailMessage
from imap_tools import MailBox

def save_draft(to_addr, subject, body):
    """Сохраняет письмо в папку черновиков IMAP."""
    msg = EmailMessage()
    msg["From"] = os.getenv("IMAP_USER")
    msg["To"] = to_addr
    msg["Subject"] = f"Re: {subject}" if not subject.lower().startswith("re:") else subject
    msg.set_content(body)

    # имя папки черновиков зависит от провайдера
    drafts_folder = guess_drafts_folder()

    with MailBox(os.getenv("IMAP_HOST")).login(
        os.getenv("IMAP_USER"), os.getenv("IMAP_PASS")
    ) as mailbox:
        mailbox.append(msg.as_bytes(), drafts_folder)


def guess_drafts_folder():
    """У разных провайдеров папка называется по-разному."""
    host = os.getenv("IMAP_HOST", "")
    if "gmail" in host:
        return "[Gmail]/Drafts"
    if "yandex" in host:
        return "Drafts"
    if "mail.ru" in host:
        return "Черновики"
    return "Drafts"  # дефолт по стандарту

Если не знаешь, как называется папка — выведи список:

with MailBox(host).login(user, password) as mailbox:
    for folder in mailbox.folder.list():
        print(folder.name)

Шаг 5: дневной чек-ин в Telegram

import asyncio
from telegram import Bot

async def send_brief(stats, urgent_items, template_count):
    bot = Bot(token=os.getenv("TG_BOT_TOKEN"))

    lines = [
        f"📬 *Утренний бриф*",
        f"",
        f"🔴 Срочное: {stats['urgent']}",
        f"🟡 FYI: {stats['fyi']}",
        f"⚪️ Шум: {stats['noise']}",
        f"✉️ Черновиков подготовлено: {template_count}",
    ]

    if urgent_items:
        lines.append("\n*Что важно сегодня:*")
        for item in urgent_items[:5]:
            lines.append(f"• _{item['from']}_: {item['subject']}")
            lines.append(f"  └ {item['reason']}")

    await bot.send_message(
        chat_id=os.getenv("TG_CHAT_ID"),
        text="\n".join(lines),
        parse_mode="Markdown",
    )

Шаг 6: собираем main.py

import asyncio
from collections import Counter
from dotenv import load_dotenv

from fetch_inbox import fetch_recent_emails
from classify import classify_batch
from drafts import save_draft
from telegram_brief import send_brief

load_dotenv()

def main():
    emails = fetch_recent_emails(hours=24)
    print(f"Достал {len(emails)} писем")

    if not emails:
        asyncio.run(send_brief({"urgent": 0, "fyi": 0, "noise": 0}, [], 0))
        return

    results = classify_batch(emails)

    # индекс uid → email для быстрого матчинга
    email_by_uid = {e["uid"]: e for e in emails}

    stats = Counter()
    urgent_items = []
    draft_count = 0

    for r in results:
        stats[r["category"]] += 1

        if r["category"] == "urgent":
            e = email_by_uid.get(r["uid"], {})
            urgent_items.append({
                "from": e.get("from", "?"),
                "subject": e.get("subject", "?"),
                "reason": r.get("reason", ""),
            })

        if r["category"] == "template" and r.get("draft"):
            e = email_by_uid.get(r["uid"])
            if e:
                save_draft(e["from"], e["subject"], r["draft"])
                draft_count += 1
                print(f"Draft → {e['from']}")

    asyncio.run(send_brief(dict(stats), urgent_items, draft_count))
    print("Готово.")


if __name__ == "__main__":
    main()

Запуск и проверка

Первый запуск — вручную, в боевом режиме на свежей почте:

python main.py

Что проверить:

  • В Telegram пришёл бриф с цифрами.
  • В папке «Черновики» твоего почтового клиента появились новые драфты (открой почту с телефона — обычно там черновики видны сразу).
  • Тексты драфтов адекватные — не приторно-вежливые, по делу, в твоём стиле.

Когда убедился, что работает — ставь на cron. На Mac/Linux:

crontab -e
# добавь строку (каждый будний день в 8:00):
0 8 * * 1-5 cd /path/to/ai-secretary && /path/to/venv/bin/python main.py >> log.txt 2>&1

Расширения

  • Автотегирование в почте. Вместо просто чтения — добавляй IMAP-флаги/метки: «\Flagged» на срочное, «AI-noise» на шум. В Gmail/Yandex поддерживается. Потом фильтром в почте → шум сразу в архив.
  • Экспорт TODO. Если в письме просьба «сделай X к четвергу» — отдельный класс «task», и draft = добавить в Things 3 / Notion / Todoist через их API. Я делал в Things через URL-схему — три строчки.
  • Пятничный стендап. По пятницам в 17:00 второй cron-джоб: пробегает по отправленным письмам за неделю, выдаёт «вот что ты сделал» — удобно для отчёта руководителю или для себя в журнал.
  • Few-shot стиль. Подсунь Claude 5–10 примеров своих реальных ответов — драфты станут заметно «твоими» по интонации. Я храню примеры в отдельном .txt и подгружаю в system-промпт.
  • Свой ICP для важности. Список «эти 10 email — всегда urgent» хардкодом в промпт. Письмо от босса/жены/нотариуса не должно случайно улететь в FYI.

Подводные камни

  • Rate-limit IMAP. Gmail позволяет до 15 одновременных IMAP-сессий с аккаунта. Если случайно запустил скрипт в цикле — забанят на час. Всегда выходи из with MailBox(), не держи коннект.
  • Приватность. Ты отправляешь содержимое писем в Anthropic. Если в почте врачебная тайна, NDA, банковские данные — подумай, готов ли ты к этому. Anthropic не тренирует на API-данных, но это всё равно твой выбор. На корпоративную почту я бы такое не ставил без согласования с безопасностью.
  • AI промахнётся. Иногда «важное от клиента» уйдёт в FYI. Поэтому скрипт никогда не удаляет, не архивирует и не отправляет письма сам — только классифицирует и готовит драфты. Все деструктивные действия — за тобой.
  • Длинные треды. Если в одном письме висит переписка на 50 круток — обрезка до 1500 символов отрежет историю. Можешь брать msg.text[:5000], но следи за стоимостью токенов. Для сотни писем в день — копейки, для тысячи — уже заметно.
  • Папка «Черновики» в Gmail. Называется [Gmail]/Drafts, в кавычках с пробелом перед /. Если опечатаешься — IMAP молча создаст одноимённую папку, и в почтовом клиенте драфты не появятся. Проверяй через mailbox.folder.list().
  • HTML-письма. msg.text у некоторых рассылок пустой, всё в msg.html. В коде выше — фолбэк msg.text or msg.html, но HTML с тегами засоряет модели контекст. Можно подключить html2text для очистки.

Что в итоге

У меня скрипт живёт 4 месяца. По метрикам: время на разбор inbox упало с ~40 до ~10 минут утром. Из 5–8 драфтов в день я отправляю «как есть» 3–4, остальное правлю на 1–2 строки. Раз в две недели бывает промах классификации — но за всё время ни одно реально критичное письмо не оказалось замолчано: они почти всегда уходят в «urgent».

Главный нелинейный эффект — психологический. Открываешь почту не с тошнотой «опять 60 непрочитанных», а с пониманием «у меня 3 важных, я знаю какие». Это меняет утро.

Без VPN и подписок: полностью локальная версия — без западных API, без подписок, ничего не уходит в облако — урок p21 (AI-секретарь на Ollama).
