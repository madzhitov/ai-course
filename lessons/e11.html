Урок e11. AI без VPN — какие модели работают из коробки

Зачем тебе этот урок

Если ты сейчас в России (или другой стране, где Claude/ChatGPT недоступны напрямую), у тебя три варианта: VPN + зарубежная карта, российские модели или локальный AI на своём ноутбуке. Этот урок — карта местности.

Главный вопрос — не «что лучше», а «что окупает заморочки». Иногда заморачиваться с VPN ради Claude — оправдано (программирование, сложные тексты). Иногда — нет, и российский GigaChat или китайский DeepSeek справляются. А для совсем чувствительных задач — Ollama на твоём железе, без всяких облаков.

Важная оговорка: цены и лимиты на эти сервисы быстро меняются. Я даю структуру и порядки величин. Перед регистрацией — обязательно сверь актуальное в личных кабинетах. Прямые ссылки в каждом разделе.

2. YandexGPT — российский, по рублям, без боли

Что это и какие модели

LLM от Яндекса, доступная через Yandex Cloud. На момент написания актуальны:

  • YandexGPT Lite — быстрая, дешёвая. Для простых задач (саммари, классификация).
  • YandexGPT (Pro) — основная. Качество ближе к GPT-3.5-Turbo, но по-русски лучше многих зарубежных.
  • YandexGPT 5 — последняя версия (на момент 2025), заметно лучше предыдущих по reasoning.

Регистрация — пошагово

  1. Заходишь в Yandex Cloud Console: console.cloud.yandex.ru
  2. Логин через Yandex ID (если нет — создашь за минуту)
  3. Создаёшь облако и каталог (просто нажимаешь «Создать»)
  4. В каталоге создаёшь сервисный аккаунт с ролью ai.languageModels.user
  5. Создаёшь API-ключ для этого аккаунта — копируешь и сохраняешь (показывается один раз)
  6. Привязываешь карту для оплаты (любая российская карта работает)

Первый запрос — Python

import requests

FOLDER_ID = "b1g..."     # из консоли Yandex Cloud
API_KEY   = "AQVN..."    # созданный API-ключ

headers = {
    "Authorization": f"Api-Key {API_KEY}",
    "x-folder-id": FOLDER_ID,
}

data = {
    "modelUri": f"gpt://{FOLDER_ID}/yandexgpt/latest",
    "completionOptions": {"temperature": 0.3, "maxTokens": 500},
    "messages": [
        {"role": "system", "text": "Ты — внимательный редактор."},
        {"role": "user", "text": "Сократи: 'В современном мире AI стал...' до 1 предложения."}
    ]
}

r = requests.post(
    "https://llm.api.cloud.yandex.net/foundationModels/v1/completion",
    headers=headers, json=data
)
print(r.json()["result"]["alternatives"][0]["message"]["text"])

Сильные и слабые стороны

Сильно: русский язык, документация на русском, интеграция со Speech / Translate / Vision (тоже от Яндекса), оплата с любой РФ-карты, поддержка по-русски.

Слабее: контекстное окно меньше (обычно 8k-32k токенов), код и сложный reasoning — заметно слабее Claude/GPT-4. Function calling есть, но менее зрелый.

Цены (порядки величин)

~₽0.20–0.40 за 1000 токенов входа в YandexGPT Pro. Проверь актуальное: yandex.cloud/docs/foundation-models/pricing

3. GigaChat — Сбер, есть приличный бесплатный тир

Что это и какие модели

  • GigaChat-Lite — быстрая, для простого
  • GigaChat — основная
  • GigaChat-Pro — более мощная (платно)
  • GigaChat 2 (с сентября 2024) — заметный шаг вперёд

Регистрация — пошагово

  1. Заходишь на developers.sber.ru → GigaChat
  2. Логин через Сбер ID
  3. Выбираешь тариф: для физлица есть бесплатный с 1 млн токенов/месяц
  4. Получаешь Authorization Key (длинная строка для OAuth2)

Первый запрос — Python через SDK

pip install gigachat

from gigachat import GigaChat

# Authorization Key из личного кабинета
AUTH_KEY = "ZGM..."

with GigaChat(credentials=AUTH_KEY, verify_ssl_certs=False) as g:
    response = g.chat({
        "messages": [
            {"role": "system", "content": "Ты — пишешь сухо и по делу."},
            {"role": "user", "content": "Объясни RAG в 2 предложениях."}
        ],
        "temperature": 0.3,
        "max_tokens": 200,
    })
    print(response.choices[0].message.content)

Примечание про verify_ssl_certs=False: у Сбера свой корневой сертификат (Минцифры). Для прода — установи root-сертификат правильно, для эксперимента в скрипте можно так.

Сильные и слабые стороны

Сильно: бесплатный тир на 1М токенов/мес — реально много для пет-проекта. Хороший русский, интеграция с Kandinsky для генерации картинок прямо в API. Function calling есть.

Слабее: код — слабее Yandex и сильно слабее Claude. Документация местами хуже Яндекса. SSL-сертификат от Минцифры — нужно настраивать.

Цены

1 млн токенов/месяц бесплатно. Сверху — около ₽1.50 за 1000 токенов в Pro. Актуально здесь: developers.sber.ru/portal/products/gigachat-api

4. DeepSeek — почти Claude, в 20 раз дешевле

Что это

Китайская LLM, API совместим с OpenAI. Не блокирует РФ. По качеству — особенно DeepSeek-R1 (reasoning-модель) — реально близко к GPT-4 и Claude Sonnet на многих задачах, особенно код и логика. Цена на порядок ниже.

Главная боль: оплата. Карты UnionPay принимаются (некоторые российские банки их выпускают), Visa/MC — нет. Или через прокси-сервисы.

Регистрация

  1. platform.deepseek.com — регистрируешься по email
  2. Привязываешь карту (UnionPay или через посредника gpt-keys / EasyBank)
  3. Создаёшь API-ключ

Первый запрос — Python (как OpenAI)

pip install openai

from openai import OpenAI

client = OpenAI(
    api_key="sk-...",
    base_url="https://api.deepseek.com/v1"
)

resp = client.chat.completions.create(
    model="deepseek-chat",            # или deepseek-reasoner для R1
    messages=[
        {"role": "system", "content": "Ты — старший разработчик. Отвечай кратко."},
        {"role": "user", "content": "Объясни, почему async/await в Python — это не настоящий параллелизм."}
    ],
    temperature=0.3,
)
print(resp.choices[0].message.content)

Сильные и слабые стороны

Сильно: почти топ-качество, особенно DeepSeek-R1 для код-задач. Безумно дёшево. OpenAI-совместимый API — переключаешься одной строкой. Не блокирует РФ.

Слабее: оплата — главная заморочка. По русскому — приличный, но слабее GigaChat/YandexGPT в специфических нюансах. Контекст у DeepSeek — приличный (64k+).

Цены

~$0.14 за 1М токенов входа на deepseek-chat. Это в 20 раз дешевле Claude Sonnet и в 30 раз — GPT-4o. Актуально: api-docs.deepseek.com/quick_start/pricing

5. Локально через Ollama — никаких облаков

Что это

Ollama — программа, которая запускает open-source LLM прямо на твоём ноутбуке. Без интернета, без API-ключей, без оплаты, без передачи данных в облако. Идеально для приватных задач (медкарты, договоры, личная переписка).

Подробный отдельный проект про это — p14 «Локальный AI на Ollama» в тропинке мини-проектов. Здесь — быстрая выжимка.

Регистрация = установка

  1. Скачиваешь Ollama: ollama.com (Mac / Linux / Windows)
  2. В терминале: ollama pull qwen2.5:7b (скачает ~5 ГБ)
  3. Запуск: ollama run qwen2.5:7b — и сразу чат в терминале

Лучшие модели для русского

  • Qwen 2.5 / Qwen 3 — китайская, отлично работает с русским. 7B / 14B / 32B / 72B
  • DeepSeek-R1 distilled — облегчённые версии reasoning-модели
  • Llama 3.3 — русский так себе, но топ в коде
  • Gemma 2 — лёгкая, быстрая, неплохой русский

Что выбрать под железо

Сильно: приватность абсолютная. Никаких блокировок. Никакой оплаты. Работает в самолёте.

Слабее: на слабом ноутбуке (8 ГБ) — модели маленькие и слабые. Качество — заметно ниже Claude / DeepSeek-R1. Сложно с длинными документами (контекст меньше).

6. Один и тот же промпт в четырёх моделях — для калибровки

Чтобы ты понимал реальную разницу, вот пример. Промпт: «Объясни, что такое RAG, для маркетолога без техобразования, в 3 предложениях».

YandexGPT Pro: «RAG (Retrieval-Augmented Generation) — это способ улучшить ответы AI, добавляя к ним информацию из ваших документов. Сначала система ищет нужные тексты в базе, потом передаёт их AI вместе с вопросом. Так AI отвечает на вопросы по вашим материалам, не выдумывая.»

GigaChat: «RAG — это технология, которая делает AI умнее, давая ему доступ к вашим документам в момент ответа. Вместо того чтобы полагаться только на свои знания, модель сначала ищет нужное в вашей базе, потом строит ответ. Это убирает галлюцинации и позволяет AI работать с актуальными данными вашей компании.»

DeepSeek-V3: «RAG — это когда AI перед ответом сначала ищет информацию в твоих документах (как поиск в Google по твоей базе), а потом использует найденное для ответа. Без RAG модель отвечает только из того, что знала на момент обучения, и может выдумывать. С RAG — отвечает по твоим реальным материалам, и можно проверить откуда взято.»

Qwen2.5:7b (локально): «RAG (Retrieval-Augmented Generation) — метод, при котором AI получает данные из внешнего источника. Это помогает давать точные ответы на основе ваших документов. Используется, чтобы AI работал с актуальной информацией.»

Видишь разницу: DeepSeek даёт самое разговорное и понятное объяснение. GigaChat и Yandex — приличные, чуть более «корпоративные». Qwen локально — самое сухое, но рабочее.

Это не значит, что DeepSeek всегда лучший — на других задачах расклад меняется. Но видно, что все четыре варианта дают рабочий результат. Заморачиваться с VPN ради Claude — оправдано не всегда.

7. Какой выбрать под твою задачу

  • Простые тексты по-русски, ассистент-помощник: GigaChat (бесплатно 1М/мес) или YandexGPT
  • Код, сложные задачи, reasoning: DeepSeek (если разобрался с оплатой) или Claude через VPN
  • Длинные документы, контекстное окно 100k+: Claude через VPN — пока альтернатив нет
  • Приватные данные, медкарты, личное: Ollama локально
  • Картинки + текст: GigaChat (с Kandinsky) или Yandex Vision + YandexGPT
  • Function calling / tool use: YandexGPT, GigaChat, DeepSeek — все умеют, но Claude/GPT пока зрелее

8. Чего НЕ ждать

  • Полного паритета с Claude/GPT-4. На сложных задачах (длинная разработка, тонкая работа со стилем) Claude/GPT всё ещё впереди. Это сокращается, но пока правда.
  • Vision на уровне Claude. Распознавание сложных сцен на фото у российских моделей слабее. Простые сценарии (текст с фото, очевидные объекты) — работают.
  • Стабильности тарифов. Все три РФ-friendly сервиса меняют цены и лимиты часто. Закладывай это в планы.
  • Опыта «как у ChatGPT». Веб-интерфейсы Yandex и Сбер — попроще, без Project, без Memory, без Voice mode такого как у ChatGPT. Это API-сервисы первым делом.

9. Глоссарий

API-ключ
Длинная строка-пароль, которую ты передаёшь сервису, чтобы он знал, что это ты. Не показывай никому, не коммить в Git.
Токен
Кусочек текста, на которые модель «нарезает» твой запрос. ~3 символа = 1 токен для русского. См. урок 1 курса.
OpenAI-совместимый API
Когда новый сервис копирует структуру эндпоинтов OpenAI. Ты можешь использовать любой OpenAI-SDK, просто меняешь base_url и ключ. Это сейчас отраслевой стандарт.
OAuth2
Способ авторизации, при котором ты обмениваешь свой Authorization Key на временный токен доступа. У GigaChat именно так. У Yandex и DeepSeek — проще, через постоянный API-ключ.
Reasoning-модель
LLM, которая «думает» перед ответом — генерирует невидимый пользователю поток рассуждений, потом даёт финальный ответ. DeepSeek-R1, OpenAI o1 / o3 — примеры. Для сложных задач — заметно лучше обычных моделей.
Локальная модель
LLM, запущенная на твоём железе через Ollama, LM Studio или подобное. Не отправляет данные в облако. Качество зависит от размера модели и от RAM ноутбука.

10. Практика (25 минут)

  1. Выбери один сервис для теста. Самый быстрый старт — GigaChat (есть бесплатный тир). Самый «качественный» вход — Yandex (понятная документация). Самый дешёвый с топ-качеством — DeepSeek (если справишься с оплатой).
  2. Зарегистрируйся и получи API-ключ по инструкции из раздела про выбранный сервис.
  3. Сделай первый запрос — скопируй Python-пример из урока, вставь свой ключ, запусти. Если нет Python — попроси Claude/ChatGPT (или другую модель) сделать тот же запрос в командной строке через curl.
  4. Прогон 3 одинаковых промпта — например, «Саммари этого текста в 5 пунктах» — через выбранную модель и через Claude/ChatGPT (если у тебя есть доступ). Сравни.
  5. Реши, что брать дальше. Если для твоих задач выбранный сервис «дотягивает» — отлично, не нужны заморочки с VPN. Если нет — знаешь, ради чего стоит заморочиться.

11. Проверь себя

1. Самый дешёвый из трёх облачных вариантов?
DeepSeek — около $0.14 за миллион входных токенов, на порядок дешевле остальных. Главный «налог» — заморочки с оплатой.

2. Где есть приличный бесплатный тир?
GigaChat — 1 млн токенов в месяц для физлиц. Это реально много для пет-проекта.

3. Какой вариант полностью приватный?
Ollama — модель крутится на твоём ноутбуке, ничего не отправляется наружу. Минус — качество зависит от железа.

4. У какой модели картинки в API?
GigaChat через интеграцию с Kandinsky. У YandexGPT отдельно YandexART, у DeepSeek и Ollama — нет генерации картинок из коробки.

5. Когда всё-таки стоит заморочиться с Claude через VPN?
Сложный код, очень длинные документы (200k+ токенов), тонкая работа со стилем письма, продвинутые промпт-инженерные паттерны. Для большинства бытовых задач — РФ-friendly варианты справляются.

12. Что должно остаться в голове

  1. «AI без VPN» — это реальность, не компромисс. Для большинства задач YandexGPT / GigaChat / DeepSeek / Ollama дают рабочий результат. Заморачиваться с VPN ради Claude — оправдано не всегда.
  2. Под каждую задачу — своя модель. Простой ассистент по-русски — GigaChat. Код и reasoning — DeepSeek. Приватное — Ollama. Универсального ответа нет.
  3. Бесплатно начать — реально. 1 млн токенов GigaChat в месяц + локальный Qwen через Ollama = старт без копейки.
  4. API-стек одинаковый. Освоил вызов одного — освоил всех. DeepSeek вообще через OpenAI SDK, остальные через requests + одинаковый паттерн.
  5. Сверяй цены и лимиты в момент использования. Этот урок даёт карту и порядки величин. Точные цифры быстро устаревают — все три сервиса меняют тарифы регулярно.
