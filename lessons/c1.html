Claude Artifacts — генерация кода и UI прямо в чате

Цель: освоить главную фичу Claude для разработчиков и не-разработчиков Время: ~40 минут Источник: docs.claude.com, anthropic.com/news

Зачем тебе этот урок

Если ты используешь Claude как «ChatGPT, но другой» — ты теряешь самую сильную его фичу. Artifacts — это режим, в котором Claude генерирует отдельные интерактивные артефакты рядом с чатом: рабочий код, HTML-страницы, React-компоненты, документы, диаграммы. Они открываются в собственной панели справа, ими можно итерировать, копировать, делиться.

Это меняет UX работы с моделью: вместо «получил текст → скопировал → вставил в редактор → запустил» — ты видишь работающий результат прямо в чате и итерируешь по нему. Для не-программистов это часто единственный способ получить рабочий код, не имея среды разработки.

1. Что такое Artifacts

Artifact — это любой самодостаточный кусок контента, который удобнее показать в отдельной панели, а не в потоке чата:

  • Код длиннее ~15 строк (Python, JS, TS, любой язык).
  • HTML/CSS/JS, который можно сразу запустить в превью.
  • React-компоненты — рендерятся вживую.
  • SVG-графики и диаграммы.
  • Markdown-документы.
  • Mermaid-схемы.

Когда Claude видит, что ответ подходит под Artifact — он автоматически выносит его в правую панель. У тебя появляется:

  • Текст ответа в чате слева.
  • Артефакт справа с превью + кодом.
  • Кнопки: Copy, Download, Publish, Remix.

2. Как включить Artifacts

В claude.ai:

  1. Profile (нижний левый угол) → Settings.
  2. Feature Preview → включи Artifacts.

В Claude Projects (доступно на Pro/Team) — включается автоматически.

В API: ничего отдельного не нужно. Claude сам решает в зависимости от ответа. Но в API артефакты возвращаются как обычный текст — UI рендеринг есть только в claude.ai.

3. Триггеры — когда Claude создаёт Artifact

Claude автоматически создаёт артефакт когда:

  • Просишь написать код длиннее ~15 строк.
  • Просишь HTML-страницу или React-компонент.
  • Просишь длинный документ (резюме, статью, спецификацию).
  • Просишь схему, диаграмму, SVG.
  • Контент будут переиспользовать или модифицировать.

Не создаёт когда:

  • Короткие сниппеты кода (для иллюстрации).
  • Объяснения, ответы на вопросы.
  • Длинный текст в потоке диалога без переиспользования.

Можно явно попросить: «Сделай это как Artifact» или «Не делай Artifact, ответь в чате».

4. Виды артефактов с примерами

Код

Запрос: «Напиши Python-скрипт, который читает CSV с колонками date,amount, группирует по месяцам и строит график matplotlib».

Claude создаст Artifact с готовым скриптом. Можно скопировать целиком, можно попросить «добавь подсчёт среднего» — Claude обновит тот же артефакт, не создавая новый.

HTML — работает прямо в превью

Запрос: «Сделай интерактивный калькулятор ипотеки на чистом HTML/JS. Показывает график погашения. Один файл».

В правой панели появится живой рабочий калькулятор, в который можно вводить значения. Внизу — кнопка View Code, чтобы посмотреть исходник.

React-компонент

Запрос: «React-компонент: список задач с приоритетами, drag-and-drop, сохранение в localStorage».

Получаешь работающий компонент с Tailwind-стилями. Можно использовать в своём проекте — Claude использует компоненты из shadcn/ui, lucide-react, recharts.

Mermaid-диаграмма

Запрос: «Нарисуй mermaid-схему процесса от заявки клиента до оплаты в нашей CRM».

Получаешь рендеренную диаграмму + исходник.

Markdown-документ

Запрос: «Напиши спецификацию API для сервиса бронирования в формате OpenAPI».

Получаешь полный markdown-документ с разделами, который можно скачать.

SVG

Запрос: «SVG-логотип для кофейни. Минималистичный, чашка с паром, моно-цвет».

Получаешь готовый SVG, который рендерится в превью.

5. Итерация по Artifact

Главная сила — Claude помнит текущий артефакт и может его итеративно дорабатывать. Вместо переписывания целиком, он применяет частичные изменения.

Пример сессии:

Ты: «Сделай React-компонент карточки товара с фото, ценой, кнопкой Купить»
Claude: [создаёт Artifact с базовым компонентом]

Ты: «Добавь скидку — показывать старую цену зачёркнутой и процент скидки»
Claude: [обновляет тот же Artifact, не создавая нового]

Ты: «Сделай адаптивно для мобильных»
Claude: [снова обновляет]

Ты: «А теперь добавь анимацию при наведении»
Claude: [снова обновляет]

В правой панели появляется версионирование — можешь переключаться между версиями стрелками.

6. Publish и Remix

Publish — превратить артефакт в публичную ссылку. Любой может открыть и использовать. Полезно для:

  • Поделиться калькулятором с коллегой.
  • Опубликовать live-демо мини-инструмента.
  • Создать публичную страничку с инфографикой.

Ссылка вида claude.site/artifacts/xxx.

Remix — взять чужой опубликованный артефакт и продолжить итерации в своём чате. Это относительно новая возможность: фактически появляется экосистема «AI-приложений в один клик».

7. Лимиты и подводные камни

Что Artifacts не умеет

  • Backend. Только клиентский код — HTML, JS, React. Нельзя поднять Express-сервер.
  • Внешние API. Из артефакта нельзя дёргать сторонние API (CORS, безопасность). Можно только статичные данные.
  • localStorage в коде — поддерживается локально в превью, но не сохраняется между сессиями.
  • Большие зависимости. Доступны: Tailwind, shadcn/ui, lucide-react, recharts, mathjs, lodash, d3, plotly, three.js, papaparse, sheetjs, mammoth, tone, tensorflow. Но не любые npm-пакеты.
  • Файлы. Один артефакт = один файл. Если нужен мульти-файл проект — придётся компоновать в один.

Когда Artifacts мешает

Иногда Claude неуместно создаёт артефакт там, где ты хотел просто увидеть код в чате. Тогда:

  • «Покажи код прямо в чате, не в Artifact».
  • «Это просто пример, не делай Artifact».

8. Реальные сценарии использования

Для разработчика

  • Прототип компонента до открытия IDE.
  • Mini-tool для команды (интерактивный калькулятор, конвертер, чек-лист).
  • Быстрая визуализация данных — кидаешь CSV, просишь график.
  • Mermaid-схемы для документации.

Для не-разработчика

  • Сделать рабочий калькулятор без программиста.
  • Презентация / лендинг как HTML.
  • Интерактивный квиз для команды.
  • Personal dashboard с твоими метриками.

Для образования

  • Интерактивные демо для учебных материалов.
  • Мини-симуляторы (физика, биология).
  • Самопроверочные тесты.

9. Почему именно Claude, а не ChatGPT

У ChatGPT есть Canvas — концептуально похоже, но:

  • Artifacts появились раньше и более зрелые.
  • Claude лучше пишет код — это проявляется и в артефактах.
  • Live-превью HTML/React работает без отдельных шагов.
  • Publish/Remix — уникальная фича Claude.

На 2026 это одна из главных причин выбирать Claude для итеративной работы.

10. Практика (40 минут)

Упражнение 1. Калькулятор за 10 минут

Открой claude.ai. Запроси: «Сделай интерактивный калькулятор тонн CO₂ от перелётов: ввожу количество км и тип самолёта, получаю кг CO₂. Современный дизайн на Tailwind.»

Поэкспериментируй: попроси добавить выбор класса (эконом/бизнес), сравнение с другими активностями, многократные перелёты.

Упражнение 2. SVG-инфографика

«SVG-инфографика про мою неделю: 7 столбиков (Пн–Вс), высота = часы продуктивной работы. Ниже — общая сумма часов и средний день.»

Подбери цвета. Скачай. Используй где-то в реальной жизни.

Упражнение 3. Спецификация для своего pet-проекта

Если ты решил, какой будет твой сквозной проект курса (см. «Как заниматься») — попроси Claude написать markdown-спецификацию: цель, юзкейсы, MVP, нон-цели, метрики успеха.

Упражнение 4. Mermaid-схема процесса

Возьми любой процесс из своей работы (онбординг сотрудника, обработка заявки, релизный цикл). Попроси Claude нарисовать mermaid-схему. Получи документ для команды.

11. Проверь себя

1. Artifacts создаются автоматически или нужно явно просить?
Автоматически, когда Claude видит что ответ — самодостаточный код/документ. Можно явно сказать «как Artifact» или «не делай Artifact».

2. Какие технологии работают в HTML/React-артефактах?
Tailwind CSS, shadcn/ui, lucide-react, recharts, d3, plotly, three.js, lodash, mathjs. React + хуки. Не работают: localStorage между сессиями, внешние API, backend.

3. Что такое Remix?
Возможность взять чужой опубликованный артефакт и продолжить итерации в своём чате. Создаёт экосистему мини-приложений «в один клик».

4. Главный плюс по сравнению с обычным текстовым ответом?
Live-превью + итеративная доработка одного и того же артефакта без переписывания. Версионирование. Шаринг.

5. Когда Artifacts не подходит?
Backend-код, мульти-файл проекты, тяжёлые зависимости, что-то требующее внешних API.
