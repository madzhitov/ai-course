Проект «За 1 час»: Свой MCP-сервер для Claude

Что построим: MCP-сервер, который даёт Claude доступ к твоему Notion / Linear / своему API Время: ~75 минут Уровень: Python + урок c3 (про MCP)

Зачем

MCP (Model Context Protocol) — открытый стандарт от Anthropic, позволяющий Claude подключаться к любым твоим системам единым способом. Один MCP-сервер ты пишешь раз — он работает в Claude Desktop, Claude Code, Cursor, Zed и сотнях других клиентов. Этот проект научит тебя писать свой MCP-сервер за час.

Что узнаешь

  • Архитектура MCP (resources, tools, prompts).
  • Использование Python MCP SDK.
  • Подключение сервера к Claude Desktop.
  • Дебаг через MCP Inspector.

Архитектура

Claude Desktop ↔ stdio ↔ твой MCP-сервер ↔ Notion API
                                    ↘ Linear API
                                    ↘ твоя БД

Шаг 1. Установка (5 мин)

pip install mcp anthropic-mcp

Создай папку проекта my-mcp и файл server.py.

Шаг 2. Минимальный сервер (15 мин)

from mcp.server.fastmcp import FastMCP

mcp = FastMCP("my-tools")

@mcp.tool()
def get_weather(city: str) -> str:
    """Получает погоду в городе."""
    # Здесь реальный вызов API
    return f"В городе {city} +18°C, солнечно"

@mcp.resource("note://daily")
def daily_note() -> str:
    """Текущая дневная заметка."""
    return open("daily.md").read()

if __name__ == "__main__":
    mcp.run()

Шаг 3. Подключаем к Claude Desktop (10 мин)

Открой ~/Library/Application Support/Claude/claude_desktop_config.json (Mac) или %APPDATA%Claudeclaude_desktop_config.json (Win):

{
  "mcpServers": {
    "my-tools": {
      "command": "python",
      "args": ["/полный/путь/к/server.py"]
    }
  }
}

Перезапусти Claude Desktop. В чате появится 🔌-иконка с твоим сервером.

Шаг 4. Реальный tool — Notion (25 мин)

Получи Notion API key (developers.notion.com), share свою базу с интеграцией. Добавь:

import requests, os
NOTION_KEY = os.environ["NOTION_KEY"]
DATABASE_ID = "..."

@mcp.tool()
def create_notion_task(title: str, status: str = "Todo") -> str:
    """Создаёт задачу в Notion."""
    r = requests.post(
      "https://api.notion.com/v1/pages",
      headers={"Authorization": f"Bearer {NOTION_KEY}", "Notion-Version": "2022-06-28"},
      json={"parent": {"database_id": DATABASE_ID},
            "properties": {"Title": {"title": [{"text": {"content": title}}]},
                          "Status": {"select": {"name": status}}}}
    )
    return f"Created: {r.json().get('url')}"

Шаг 5. Дебаг через MCP Inspector (10 мин)

npx @modelcontextprotocol/inspector python server.py

Откроется веб-UI на localhost:5173. Можешь тестировать tools без Claude.

Шаг 6. Расширения

  • Добавь resources — статические данные (твоя текущая страница в Notion).
  • Добавь prompts — шаблоны промптов (review my today's tasks).
  • Сделай auth через OAuth (для прода).
  • Опубликуй на mcp-servers.dev.
