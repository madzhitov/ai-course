## Шесть слоёв

| Слой | Что выбираете |
|---|---|
| Модель | Что обрабатывает контекст и предлагает ответ или действие |
| Агент | Что соединяет модель с файлами, командами и другими инструментами |
| Рабочая среда | Где ставите задачи и проверяете изменения: приложение, IDE или ADE |
| Место выполнения | Где работают инструменты: компьютер, сервер, облачная среда |
| Канал общения | Окно, терминал, Telegram |
| Доступ и оплата | Подписка, прямой API или шлюз моделей |

Агент на вашем компьютере может обращаться к облачной модели.
Чат тоже может иметь инструменты. «Обсуждаю в чате» описывает способ работы автора.

## Варианты сетапа

| Вариант | Когда полезен | Что проверить |
|---|---|---|
| Готовое приложение | Обсуждение, исследование, подготовка ТЗ; агентные задачи в пределах функций приложения | Инструменты и лимиты тарифа |
| Агент на компьютере | Локальные файлы, документы, таблицы, код | Права, зависимости, проверка изменений |
| Редактор с агентом / IDE | Нужно видеть код и вмешиваться в реализацию | Удобство редактора и выбранной интеграции |
| Среда управления агентами / ADE | Несколько независимых задач или проектов | Разделение рабочих копий и объединение результатов |
| Агент на сервере | Фоновые задачи и обращения через мессенджер | Автозапуск, файлы на сервере, доступы и расходы |
| Гибрид | Компьютер для проектов, сервер для отдельных задач | Передача контекста и место актуальной версии |

IDE и ADE пересекаются по возможностям. Orca описывает себя как ADE и объединяет агентные сессии, терминалы, браузер и рабочие копии проекта. VS Code также поддерживает агентные сценарии. Название категории не заменяет проверку функций.

## Конфигурация Руслана

- Основа: Claude Code и Codex на Маке, работа с проектами и проверка изменений.
- Дополнение: Хермес на сервере, модели через OpenRouter, общение через Telegram и десктоп.
- По задаче, пока пробую: Orca, VS Code, OpenCode.
- Пока не проверено: запасное подключение десктопного Codex через шлюз.

Это описание автора на 13.11.2026, не внешний аудит устройств.

## Оплата и резерв

Подписка покрывает предусмотренные тарифом приложения и объём использования. API обычно оплачивается по потреблению и тоже имеет квоты, ограничения скорости и доступности. Шлюз объединяет подключение к моделям; сохраняются его условия и условия поставщиков.

Три разных изменения:

1. Другое приложение меняет рабочее окружение. Аккаунт и лимиты могут остаться прежними.
2. API вместо подписки меняет расчёты и квоты. Поставщик модели остаётся тем же.
3. Модель другого поставщика снижает зависимость от одной компании. Совместимость и качество нужно проверить заново.

Claude напрямую и Claude через шлюз всё ещё зависят от Anthropic. Сервер и шлюз сами по себе не отменяют региональные правила.

Перед сменой инструмента сохраните ТЗ, файлы проекта, инструкции, решения и критерии проверки. Дайте резерву ту же задачу в отдельной копии. Сравните результат, время, расходы и свои исправления.
