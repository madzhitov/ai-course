# 🤖 AI Курс — от пользователя к разработчику ИИ

Бесплатный курс по искусственному интеллекту на русском языке. **72 урока** в 4 фазах: от первых промптов до создания собственных агентов и обучения нейросетей.

🌐 **[Открыть курс](https://USERNAME.github.io/REPO/)** — замените на свой URL после публикации.

## Что это

Курс собран на основе четырёх открытых курсов Microsoft и переработан в единый последовательный путь:

- **Фаза 1. Пользователь** (12 уроков) — LLM, промпт-инжиниринг, безопасность, первые приложения
- **Фаза 2. Строитель** (18 уроков) — функции, RAG, агенты, мульти-агентные системы, продакшен
- **Фаза 3. Практик** (20 уроков) — нейросети с нуля, компьютерное зрение, NLP, трансформеры
- **Фаза 4. Инженер** (22 урока) — классическое ML, RL, MLOps, fine-tuning LLM

## Чем это отличается

- 📚 Один последовательный путь от полного нуля до уровня инженера
- 🇷🇺 На русском языке, с примерами под русскоязычный контекст
- 💯 Бесплатно, открыто, без регистраций
- 🎯 Каждый урок: теория + примеры с числами + рабочий код + практика + самопроверка
- ⏱ Один урок = ~50 минут чтения + ~60 минут практики
- ✅ Прогресс сохраняется в браузере

## Как использовать

1. Откройте сайт.
2. Идите по урокам по порядку — структура продумана.
3. После каждого урока — делайте практическое задание. Без практики обучения не происходит.
4. Ведите файл `progress.md` рядом — конспектируйте свои инсайты.
5. **Не больше 1 урока в день.** Глубже — полезнее, чем быстрее.
