# 🤖 AI Курс — от пользователя к разработчику ИИ

Бесплатный практический курс по искусственному интеллекту на русском языке. **72 урока в главном пути + спецветки** про Claude, мини-проекты и индустрии.

🌐 **[Открыть курс →](https://madzhitov.github.io/ai-course/)**

📬 **Автор и поддержка:** Руслан Маджитов · Telegram: [@madzhitov](https://t.me/madzhitov)

## Структура

**Главный путь — 4 фазы, 72 урока:**

- 🟢 **Фаза 1. Пользователь** (12 уроков) — LLM, промпт-инжиниринг, безопасность, первые приложения
- 🔵 **Фаза 2. Строитель** (18 уроков) — функции, RAG, агенты, мульти-агентные системы, продакшен
- 🟣 **Фаза 3. Практик** (20 уроков) — нейросети с нуля, компьютерное зрение, NLP, трансформеры
- 🟠 **Фаза 4. Инженер** (22 урока) — классическое ML, RL, MLOps, fine-tuning LLM

**Спецветки — параллельные углы:**

- 🟣 **Claude Deep Dive** (8 уроков) — Artifacts, Projects, MCP, Computer Use, Claude Code, prompt caching
- 🛠 **Мини-проекты «За 1 час»** (5 проектов) — Telegram-бот, RAG над Obsidian, голосовой ассистент, авто-ревьюер PR
- 💼 **Темы под индустрии** (5 веток) — ИИ для юристов, маркетинга, HR, разработчиков, финансов

## Чем отличается

- 📚 Один последовательный путь от полного нуля до уровня инженера
- 🟣 Глубокий блок по Claude — самый детальный на русском
- 🛠 Реальные пет-проекты, делаемые за час каждый
- 💼 Специальные ветки для разных индустрий
- 🇷🇺 На русском, с учётом российских реалий
- 💯 Бесплатно, открыто, без регистраций
- 🎯 Каждый урок: теория + примеры с числами + рабочий код + практика + самопроверка
- ✅ Прогресс сохраняется в браузере

## Как использовать

1. Открой сайт и посмотри **«О курсе»** и **«Как заниматься»**.
2. Иди по главному пути или прыгни в интересующую спецветку.
3. После каждого урока — практическое задание. Без практики обучения не происходит.
4. Веди файл `progress.md` рядом — конспектируй инсайты.
5. **Не больше 1 урока в день.** Глубже — полезнее, чем быстрее.
6. Подключись к Telegram автора [@madzhitov](https://t.me/madzhitov) для обновлений и обсуждения.
