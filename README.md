Бесплатный практический курс по искусственному интеллекту на русском языке. **139 уроков в 6 тропинках, 93 готовы и публикуются.**

**🛤 Главный путь — 4 фазы, 72 урока** (26 готовы):

- 📚 Один последовательный путь от полного нуля до уровня инженера
- 🎓 Глубокий блок по Claude — самый детальный на русском
- 🛠 22 реальных pet-проекта, каждый собирается за час
- 🏭 10 индустриальных веток с практикой под профессию
- 🥋 Отдельная тропинка про вайбкодинг с философией боевых искусств
- 🇷🇺 Учёт российских реалий: альтернативы OpenAI (YandexGPT/GigaChat), 152-ФЗ, AI без VPN
- 💯 Бесплатно, открыто, без регистраций и email-стен
- 🎯 Каждый урок: теория с числами + рабочий код + практика + самопроверка + глоссарий
- ✅ Прогресс сохраняется в браузере (localStorage)

## Как использовать

1. Открой сайт, посмотри **«О курсе»** и **«Как заниматься»**.
2. Иди по главному пути или прыгни в интересующую тропинку.
3. После каждого урока — практическое задание. Без практики обучения не происходит.
4. Веди файл `progress.md` рядом — конспектируй инсайты.
5. **Не больше 1 урока в день.** Глубже — полезнее, чем быстрее.
6. Подключись к каналу [@artefakty_ai](https://t.me/artefakty_ai) для обновлений и обсуждения.
